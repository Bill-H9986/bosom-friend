# Bosom Friend · 发布（**A 内容创作** 的最后一环）

> 三大核心归属：发布是 **A 内容创作** 的收尾动作（A4），不是独立板块。
> 创作本身走 `bosom-friend-content`；账号登录态走 `bosom-friend-account`；数据回读走 `bosom-friend-ops`。

## 一、你的职责

把**已经做好的内容**发到用户的平台账号，并**拿回平台真实作品 ID/链接**。
**只有用户在这一句话里明确要求发布，才进入本流程**——"写一篇""生成一条""做个脚本"都只是创作请求。

## 二、发布是怎么执行的（2026-09-30 起：由前端执行）

你**不直接调发布接口**。真实链路：

```
你调 bosom_publish_content（账号/素材/标题/正文/话题/位置/内容标注）
  → 服务端把参数变成一张「去发布」动作卡
  → 前端弹出发布弹窗（内容已预填）
  → 跟随模式开着 → 自动提交；没开 → 用户点「去发布」
  → 平台引擎在真实浏览器里逐项填写并提交
  → 引擎回读平台真实作品 ID，写进发布记录
```

## 三、已跑通的工作流

### 工作流：把一条素材发布到抖音

1. **查素材** `bosom_material_list` → 拿 **materialId**（用工具返回的 id，别拿文件名当内容）。
2. **查账号** `bosom_platform_list_accounts` + `bosom_platform_login_status` →
   拿 **accountId** 与登录态；**登录失效就先如实说、备好文案，不要硬发**。
3. **写文案**：标题（抖音 ≤30 字，钩子放前 8 字）/ 正文（≤1000 字，前两行给结论，
   **不得出现"请点击去发布"这类对用户说的话**）/ 话题 3~5 个（不带 #）。
   产品与卖点从语境的「内容语境」取，**不要凭素材文件名猜**。
4. **调 `bosom_publish_content`**：accountId / materialId / title / body / topics / location / declaration 一次给全。
5. **等前端**：面板出现「准备发布」卡；跟随模式开着自动提交。
6. **回读**：发布记录里出现**平台真实作品 ID/链接**才算成功。

**验证状态（2026-09-30 实测）**：
- ✅ 前端执行链路跑通：动作卡出现 → 自动提交 → 发布记录产生（`rec-okmmf01n`）
- ✅ 引擎完整走完：视频上传 → 选「内容由AI生成」→ 等 AI 推荐封面并应用 → 到发布提交
- ⚠️ **两次都卡在平台短信验证码**：产品会暂停等真人，**10 分钟内没人输就超时失败**
- ❌ 尚未拿到一次"平台真实作品 ID"

### 发布页六项（引擎在真实浏览器里逐项填）

| 项 | 要求 |
| --- | --- |
| 标题 | 抖音 ≤30 字，钩子放前 8 字 |
| 正文 | ≤1000 字，前两行最关键 |
| 话题 | 3~5 个精准词，只用平台真实存在的词 |
| 封面 | 用发布页「AI 智能推荐封面」：引擎会等生成 → 点选应用 → 截图留证 |
| 位置 | 只在内容确实与某地相关时才加 |
| 声明 | AI 生成内容必须标注「内容由AI生成」 |

## 四、遇到这些就停下等真人（绝不抢操作）

- **短信验证码**：引擎已暂停一切自动操作——**绝不点「重新发送」**（会触发平台限频）、
  不重试、不刷新（会清空已输入内容）。提醒用户去那个浏览器窗口输入，**10 分钟内有效**。
- **扫码登录**：真人动作，你负责引导与后续自动化。

## 五、失败了怎么办

| 现象 | 真实原因 | 处理 |
| --- | --- | --- |
| 弹「短信验证码」 | 平台要求真人验证 | 暂停等真人；10 分钟超时就是失败，如实说 |
| 「登录已失效」 | 账号掉登录 | 引导重新扫码，不要重试发布 |
| 「已有发布任务在进行中」 | 同账号同刻只允许一个平台任务 | 等它结束 |
| 记录长期"发布中" | 引擎还在跑或已中断 | 如实报状态，绝不改成"成功" |

## 六、边界与红线

- **没明确指令不发布**：不给发布入口、不调发布工具。
- **不伪造成功**：没有平台真实作品 ID 就不许说"已发布"。
- **不顺带发布**：创作流程里绝不"顺便帮你发了"。
- **限频**：同账号默认每天 ≤3 条、两次间隔随机 5~25 分钟。
- **只有工具调用成功才算"发布已发起"**，回复里不能只有一个"已发布"。
