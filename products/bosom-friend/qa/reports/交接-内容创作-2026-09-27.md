## 二、本轮完成的改动（按主题）

### 参考图与画面一致性
1. **i2i 走单数 `image` 字段**（`packages/media/media-pi-ai/src/vendor.ts`）—— 复数 images 会走 t2i 队列，锁不住人
2. **`attachGenerationMedia` 补传 `prompt`** —— 此前用户提示词到不了厂商，出图只用文案
3. **`mediaPrompt` 带参考图时以用户提示词为准**
4. **参考图每镜都带**（`personImageUrls` → `sceneProducer` 的 `personRefs`）—— 此前分段链路只传第 1 张
5. **固定 seed**：一条片子的所有镜头共用一个（存在生成记录 `response.seed`）
6. **登记形象 `dh-ref-xiaoya`**（3 张参考图：`ref-front/side/back.png` + seed 960750 + `avatarUrl`）

### 内容形式与编排
7. **`form` / `humanRef` 打通**（请求 → 生成记录 → `attachGenerationMedia` → 编排层）—— 融合时这两个字段被白名单丢掉，永远走缺省 `scene`
8. **接上 `digitalHumanProducer`**（`vlog` 形式 = 母时钟 + 口型 + 贴音 + 稿件）
9. **台词一律来自稿件**（丢掉分镜模型自编的推销腔）
10. **增量补写**（`rewriteInstruction` 带原稿、只要增量）—— 此前"重写一版"每轮都停在 250 字

### 声音与服装
11. **声音六要素**（按阿里云官方《声音公式》：内容+情绪+语调+语速+**音色**+口音）—— **口播镜与旁白镜用同一套**，这是"旁白男声"和"声音不确定"的根因修复
12. **服装全片只穿一套**（`continuityNote`）—— 此前一镜换一次，实测换了四次

### 视角与镜头（最新一批）
13. **第三人称旁观视角**（不要自拍视角、不要出现拿相机的手）
14. **镜头稳定**（固定机位/缓慢横移，不要手持晃动、不要甩镜）
15. **运镜表换掉**：固定机位中景 / 缓慢横移 / 接写特写 / 推近产品 / 俯拍操作台 / 缓慢环绕
16. **单一女性硬约束**（不得出现第二位女性、不得把参考图的多个角度当成多个人）
17. **竖屏三条规矩**（GOKKO 方法论）：接写、前-后纵深、每 2~3 秒新信息
18. **黄金三秒开场**（写稿硬要求：禁止"大家好"这类开场）

### 合规
19. **画面禁文字逐项列举**（招牌/门头字/证书/制度牌/公告栏/海报/包装文字/屏幕文字/水印/logo/二维码/条码/电话/车牌）
20. **平台违禁词**（按抖音官方《社区自律公约》+《创作者"诱导第三方"实施细则》）：极限词、刺激消费、诱导点击、医疗承诺、联系方式、**谐音变体**、**站内私信引导**
21. **AI 生成画面本身干净**（字幕是后期烧的，逐镜素材已验证无字幕）

### 稳定性与体验
22. **轮询指数退避**（6s→30s 封顶）—— 原来固定 4 秒，一镜 15~75 次 poll，把免费额度打满
23. **等待预算按每镜 8 分钟**（原 6 分钟，60 秒档 72 分钟不够用，会把还在跑的任务误判成 partial）
24. **失败三出口**（断点继续 / 重新生成 / 放弃）+ resume 同步回滚记录状态
25. **进度环沿卡片边框** + **全流程百分比**（写稿→逐镜→合成，成片才 100%）
26. **卡片排布统一**（3:4 图框 + 标题区 h-14 + 信息区 60px，实测 285/288）
27. **知识库污染修复**（提示词增强不再入库 + 清掉 10 条污染）
28. **提示词增强按钮**（✨ 画面口径，148~169 字）

## 三、已验证的厂商机制（实测，不要推翻）

| 事实 | 依据 |
| --- | --- |
| **参考图数量决定模式** | 1 张 = `keyframe`（画面被这张图锁死）；**≥3 张 = `reference`（锁人不锁场景）** —— 做过 A/B 对照实验 |
| 参考图硬约束 | **边长 ≥256px**、**宽高比 0.4~2.5**（否则 400） |
| 视频单次时长 | `seconds` 4~12 秒 |
| 免费档限流 | 429 是常态；**退避重试能过，频繁重启会打断重试** |
| 拼贴图有害 | 三视图拼成一张会走 keyframe，画面被锁死 |
| 手部/旁白默认男声 | 提示词不写音色时厂商默认男声 |

## 四、未完成（按优先级）

1. **抽象意象导致画面崩坏** —— 台词是"风一吹叶子哗哗响""阳光落在椅背上"这类**没有实体**的句子时，厂商生成扭曲几何体。**修法：分镜要求"每镜必须有实体场景（谁/在哪/手上拿着什么/镜头对着什么物体）"，抽象意象必须落在一个具体物件上**
2. **形象库入口放回内容创作** —— 数据层已有（`digital-humans.json`），界面随「数字人」板块下线而消失。**这是用户要的"固定人物 IP"的关键一步**
3. **场景库** —— 用户有固定场地与设备，需要"上传场地/设备图 → 命名 → 复用到每条片子"；没有它"同一个地方"不成立
4. **内容类型模板**（产品型/知识型/故事型/生活型/活动型）
5. **画面文字彻底干净** —— 厂商执行力有上限（走廊/教室天生有门牌证书），只剩后期打码一条路
6. **微信「文件传输助手」自动发送** —— 微信 4.x 是自绘窗口，**不接受剪贴板粘贴文件、不接受合成鼠标拖放、不接受合成点击**；已试三条路全部失败，只能人工拖

## 六、流程铁律（本轮违反过两次，务必遵守）

1. **改代码 → 构建 → 重启 → 确认 boot 时间 → 才提交任务**。构建了没重启 = 跑的还是旧代码
2. **任务在跑时不重启服务、不发探测请求**（重试窗口被打断就得从头来）
3. **验收看原始分辨率 + 工具量化**（`blackdetect` / `freezedetect` / `volumedetect` / 直读 ASS），不要用缩略图认字（我把"全是进口件儿真不糊弄"误读成乱码，还给用户报了假问题）
4. **不再动已验证可用的功能**（用户明确要求：做好一个功能确定能用就别随便改）
