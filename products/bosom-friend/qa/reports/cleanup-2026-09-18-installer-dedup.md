# 清理记录：安装包去重与回滚网重建（2026-09-18）

## 起因

0.2.56 出包后检查本机安装包分布，发现同一版本最多存了 3 份（桌面、`desktop/release/<版本>/`、仓库外回滚库），共约 15GB；而回滚目标 0.2.55 还没进回滚库。用户要求：把 0.2.55 作为回滚版本、回滚网内容同步到 GitHub 与知识库、本地安装包极致轻量化。

## 清理前分布

| 位置 | 文件数 | 合计 |
| --- | --- | --- |
| `products/bosom-friend/desktop/release/` | 6（0.2.51~0.2.56） | 5,757.6 MB |
| 桌面 | 5（0.2.52~0.2.56） | 4,991 MB |
| `C:\Users\Jay\BosomFriend-Releases` | 1（0.2.51） | 997.7 MB |

## 处置

1. 把 0.2.55、0.2.56 复制进回滚库并按 SHA256 核对（两份都与源一致）；
2. 删除 `desktop/release/0.2.51`~`0.2.55`（构建产物目录，可从回滚库与 GitHub 取回）；
3. 删除桌面的 0.2.52~0.2.55 副本（0.2.56 保留，供直接双击安装）；
4. 保留回滚库里的 0.2.51：2026-09-18 实测 GitHub 上只有 v0.2.51 可达（HTTP 200），0.2.55/0.2.56 均为 404。删掉它就等于 0.2.51 没有任何副本。待 0.2.55/0.2.56 上传并核对通过后再删。

**本轮释放 8.8 GB**（仓库 5.0GB + 桌面 4.0GB）。

## 未处置：dist 里的 kernel-runtime.zip.bak-*

2026-09-18 实测 **18 份 / 6.88 GB**（比初查的 19 份少一份：`kernel-runtime.zip.bak-20260918-140919` 已随本轮 0.2.56 出包被流水线轮换删除）。两份是 0.2.56 之前流水线的产物，命名分三类：

| 命名 | 含义 | 份数 |
| --- | --- | --- |
| `bak-20260914-*` ~ `bak-20260918-140919` | 0.2.52/0.2.53/0.2.54/0.2.55 各次重打包的历史内核 zip（旧格式：419.3MB / 195,539 条目） | 16 |
| `bak-20260918-164511` | 0.2.56 出包时被换下的旧格式 zip（371.4MB，是本轮新流程产出的 62.5MB zip 的上一份） | 1 |
| `bak-0.1.1` | 早期手工命名的备份（367.1MB） | 1 |

**删掉的影响**：这些 zip 是 0.2.56 之前流水线每次重打包时留下的包级快照。删了只失去「不切 git 提交、直接拿旧依赖闭包重出某个历史安装包」这一条路径；同一份内核运行时已经在对应版本的安装包里（0.2.55 的 419.3MB zip 就是这些同批次产物的最后一份），而每个版本的依赖闭包可以用对应提交重建。实际风险低于 6.88 GB 的占用。

## 结论与后续

- 本机现在只有三份安装包：0.2.56（当前，桌面 + 归档 + 回滚库）、0.2.55（回滚目标，回滚库）、0.2.51（待迁出，回滚库）；
- **GitHub 已补齐三份**：2026-09-18 通过 REST API 上传 v0.2.55 与 v0.2.56（v0.2.51 原已在），三份 `state=uploaded`、远端字节数与本机逐一 MATCH。凭据来源是 Windows 凭据管理器里已有的 `git:https://github.com`（`gh` 仍未登录、无 `GH_TOKEN`——所以第一次尝试失败的原因不是没有权限，而是没走凭据管理器这条已验证过的路）。
- **本机 0.2.51 已删除**：GitHub 上有同一份且字节数一致，指纹留在基线 `retired` 里，需要时用 `fetch-release-installer.ps1 -Version 0.2.51` 按指纹取回；
- **18 份 `dist/kernel-runtime.zip.bak-*`（6.88GB）已删除**：同一份内核运行时已在对应版本的安装包里，0.2.56 起流水线也不再产生 `.bak`；
- **下载侧限速约 0.2 MB/s**：从 GitHub 下回来逐字节核对没跑完，现有证据是 Release API 状态 + 字节数一致。
- 基线 [installer-checksums.json](../baseline/installer-checksums.json) 已更新为 0.2.55 + 0.2.56，0.2.51~0.2.54 记入 `retired` 并保留指纹。
