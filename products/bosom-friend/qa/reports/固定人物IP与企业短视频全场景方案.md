# 固定人物 IP + 企业短视频全场景方案

> 用户的问题：**有固定场地与设备，只缺一个固定的人物做 IP，怎么在内容创作里实现？** 以及 **企业做短视频运营的各种场景都要考虑到**。

## 一、结论先说：技术上产品已经具备"固定人物"的全部机制

| 机制 | 现状 |
| --- | --- |
| 同一张脸跨镜不变 | ✅ **形象图 + 固定 seed**（`digital-humans.json` 里的形象各带一个固定 seed） |
| 人物参考图喂给厂商 | ✅ **≥3 张走 reference 模式**（只锁"是谁"，场景自由）——我们做过对照实验 |
| 同一把声音 | ✅ 按阿里云官方《声音公式》写全六要素（内容+情绪+语调+语速+**音色**+口音） |
| 同一套衣服 | ✅ 本轮刚加：**全片只穿一套，剧情需要时只换一次** |
| 复现同一版画面 | ✅ 固定 seed |

**结论：「固定人物」这件事在引擎里已经成立。缺的是"把它做成产品交互"。**

## 二、缺的三块（要补的能力）

### 1. 形象库（IP 档案）
上传 3 张同一人的照片（正面 / 四分之三侧 / 侧面，同一场次同一光线）→ 命名 → **此后每条片子都能选用**。
数据层已有（`digital-humans.json`），但入口随「数字人」板块下线而消失 —— **要放回内容创作**。

### 2. 场景库（场地与设备）
用户说的"固定场地和设备"就是这一块：上传车间、教室、门店、设备照片 → 命名（"车间A""培训教室"）→ 生成时**与人物参考图一起进参考集**。
这样"同一个人在同一个地方"才成立 —— **单靠文字描述场景，每镜都会长不一样**。

### 3. 模板库（企业常见内容的骨架）
按内容类型给现成结构，用户只填主题。

## 三、企业短视频的五种内容类型（产品要全部覆盖）

| 类型 | 用途 | 依赖资产 |
| --- | --- | --- |
| **产品型** | 介绍设备 / 服务 / 工艺 | 场景 + 设备图 |
| **知识型** | 教程、科普、答疑、避坑 | 场景 + 人物 |
| **故事型** | 客户见证、学员成长、老板创业 | 人物 + 场景 |
| **生活型** | 员工日常、幕后、花絮 | 人物 + 场景 |
| **活动型** | 报名、促销、节气、政策热点 | 人物 + 场景 + 时效文案 |

## 四、产品形态（四步闭环）

```
① 建 IP    上传 3 张同一人的照片 → 命名"小雅" → 生成形象（固定 seed）
② 建场景   上传场地/设备照片 → 命名"车间A""培训教室"
③ 出内容   选 IP + 选场景 + 写主题 + 选类型 → 一键出片
④ 复用     每条片子都调用同一个 IP 与场景 → 观众认得出"同一个人、同一个地方"
```

**这就是企业 IP 的本质**：不是"每条片子都精致"，而是**同一个人、同一个地方、持续讲同一类事**。

## 五、企业运营要考虑的全部场景（清单）

**内容层**
- 五种内容类型的配比（产品 : 知识 : 故事 : 生活 : 活动 ≈ 3:3:2:1:1）
- 季节 / 节日 / 政策热点日历
- 开场三秒的四种模式（预期落差 / 痛点提问 / 视觉冲击 / 悬念）

**发布层**
- 多平台比例与时长（9:16 竖版为主，抖音/视频号/小红书各有限制）
- 封面与标题规范（标题 ≤30 字、话题 ≤10 个）
- 发布时间与频次（每天最多 2~3 条，间隔几小时）

**合规层**
- AI 生成内容标注（平台强制）
- 广告法极限词、承诺性表述
- 平台违禁词（含谐音变体）、站内私信引导
- 画面不得出现二维码/电话/车牌/水印/招牌文字

**稳定层（IP 的护城河）**
- 人物：同一张脸、同一套服装、同一把声音
- 场景：同一个场地、同一批设备
- 风格：同一色调、同一字幕样式、同一片头片尾

**效率层**
- 批量出片（同一脚本生成多平台版本）
- 素材库复用（形象 / 场景 / BGM / 片头）
- 失败可续跑（断点继续），不浪费额度

## 六、下一步要做的（按性价比）

1. **形象库入口放回内容创作**（数据已有，只缺界面）——**这一条直接实现用户要的"固定人物 IP"**
2. **场景库**（上传场地/设备图 → 命名 → 复用到每条片子）
3. **内容类型模板**（五种类型的脚本骨架）
4. **IP 一致性自检**（出片后自动抽帧比对人物/服装/色调是否漂移）
