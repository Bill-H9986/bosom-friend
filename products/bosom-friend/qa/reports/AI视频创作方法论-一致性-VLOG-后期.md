> 学习来源：Seedance 官方社区的一致性实测长文（参考包 + 提示规则）、行业剪辑节奏法则、POV VLOG 拍摄流程，以及**我们自己在 Agnes 上的对照实验**（下详）。

## 一、一致性：怎么保证"不同画面里是同一个人"

### 1.1 厂商机制：参考图**数量**决定模式（我们的实测）

Agnes 的视频接口按参考图数量切换模式（源码 `agnesModeFields`）：

| 参考图数量 | 厂商模式 | 语义 | 后果 |
| --- | --- | --- | --- |
| 0 张 | `text` | 纯文生视频 | 人物每次随机 |
| **1 张** | `keyframe`（first_frame） | **当第一帧** | **画面被这一张锁死** |
| 2 张 | `keyframe`（first+last） | 首尾帧 | 画面被两张锁死 |
| **≥3 张** | **`reference`** | **参考集：只锁"是谁"，不锁构图** | **人物保留 + 场景按提示词生成** |

**我们的对照实验（同提示词、同 seed 20260927、同 5 秒档）**：

- **A 组**：把「站立三视图」**整张**当参考图 → 走 `keyframe` → 成片**就是三视图立绘**，提示词里的"车间 / 无人机 / 螺丝刀"全部丢失。
- **B 组**：把三视图**切成三张独立图**（正面 / 侧面 / 背面）→ 走 `reference` → 成片是**第一人称视角的实操车间**：前景是操作工的手在拆装无人机、桌上有螺丝刀、货架上排着无人机，**而画面里的女性与小雅完全一致**（白衬衫 + 黑裙 + 马尾）。

> **结论：想要"人物锁住、场景自由"，就必须让它走 `reference` 模式——也就是给 **≥3 张独立**参考图。拼成一张的三视图，在厂商眼里是"一个复杂场景"，会走 keyframe 把画面钉死。**

**踩过的技术坑（同样是实测）**：
- 参考图**边长必须 ≥256px**，否则 400 `输入图边长必须在 256–5760 像素之间`；
- 参考图**宽高比必须在 0.4–2.5** 之间，否则 400 `输入图宽高比必须在 0.4–2.5 之间`（我们切出来的 1:4 窄条就是被这条挡住的，补白到 1:2 才通过）。

### 1.2 参考素材包（行业做法）

来自 Seedance 一致性实测长文，核心是「**少而清晰**」：

| 组成 | 具体要求 |
| --- | --- |
| **静帧 ≤3 张** | 一张正面、一张 3/4 侧面、一张侧面；**同一拍摄场次、相同光线**。不要混"一张微笑一张中性"——模型会取中间态，脸就变了 |
| **2–3 秒参考短片** | 中性点头或缓慢眨眼；给模型一个**下颌与眼部行为的动态基准** |
| **一个风格锚点** | 一张设定色调与对比度的静帧；跳过它，身份能保住但**氛围会漂** |

**明确无效甚至有害的做法**：
- ❌ **拼贴图**（三视图就是拼贴）——模型当复杂场景处理；
- ❌ **混合光线**（一暖一冷）——模型平均成中性值，肤色与"感知年龄"都会变；
- ❌ **只用高清头像**——插入一张中等分辨率反而更好（软化对毛孔的过拟合，保留形状）。

### 1.3 提示词规则（该固定什么、该避免什么）

**要固定**：
1. **把人物定义为单一实体**："与参考图像相同的角色，同一个身份" —— 看似废话，但它阻止模型去采样"类型变体"；
2. **年龄区间 + 头发细节 + 1~2 个识别特征**（例："20 多岁末期、深色卷发及耳垂、左耳小银环"）。**细节太少会泛化，太多会挑剔**；
3. **镜头意图与节奏**："缓慢行走、细腻表情、无大幅转头" —— **动作规范即身份规范**。

**要避免**：
- **模糊风格词**（"电影感""梦幻""粗粝"）——它们会和参考锚点打架；要风格就用**风格参考图**，别用形容词；
- **会改变轮廓的服装细节**（飘动的围巾、宽松外套）。

### 1.4 为什么会漂移（机制）

模型**先掌握宏观轮廓**（发量、身高、体型），**微观特征在压力下游移**（眼距、人中长度、耳廓、发际线）。触发点很具体：
- **手遮住脸** → 下一帧当成一次重新洗牌；
- **快速转头** → 耳部与太阳穴还原度崩；
- **重复图案的服装** → 注意力从脸转移走；
- **光线变化** → 等同于对身份做了一次"软性编辑"。

### 1.5 我们的落地清单

| # | 动作 | 现状 |
| --- | --- | --- |
| 1 | **参考图 ≥3 张时走 reference，1~2 张时明确警告"会锁死画面"** | 内核已按数量分模式 ✅，但**界面没提示** ❌ |
| 2 | **上传三视图时自动切成 3 张**（或提示用户拆开上传） | ❌ 未做 |
| 3 | **参考图校验**：边长 ≥256、宽高比 0.4~2.5，不满足时**当场提示**（而不是等厂商 400） | ❌ 未做（我们踩过两次） |
| 4 | **固定 seed**（每镜同一 seed） | 数字人链路有 ✅；**内容创作直接视频路径没有** ❌ |
| 5 | **一致性条款**（"与参考图同一个人：同一张脸/发型/服装，服装以参考图为准"） | ✅ 已加 |
| 6 | **人物锚描述**（年龄+发型+1~2 特征）写进每镜提示词 | ❌ 未做（现在是通用条款） |
| 7 | **避免手遮脸/快速转头**的镜头设计 | ❌ 未做（分镜提示词里可加约束） |

## 二、VLOG 怎么拍

### 2.1 第一人称（POV）的镜头语言

| 要素 | 做法 |
| --- | --- |
| **视角** | 相机 = 我的眼睛；前景常有**手/工具/物品**入画，制造"我在做"的代入感 |
| **运镜** | 手持轻微晃动（**要有，但别过头**）、走动时镜头随步伐起伏、转身用腰带动而不是甩头 |
| **景别** | 以**中近景 + 特写**为主：手部动作、设备细节、对方的脸；大远景只用来交代环境 |
| **光线** | 尽量**同一场次同一光线**（跟一致性是同一条约束）；室内用顶光+侧光，避免明暗跳变 |
| **声音** | 现场声（脚步、工具碰撞、环境底噪）是 VLOG 的灵魂；旁白压在上面，不要盖死 |

### 2.2 结构（留存曲线决定的结构）

| 段落 | 时长占比 | 任务 |
| --- | --- | --- |
| **钩子** | 0–3 秒 | 一句话给出"为什么值得看"（悬念/利益/反差）；**必须有人或动作在动** |
| **展开** | 3 秒–70% | 按"我遇到什么 → 怎么做 → 结果如何"推进；**每 5~8 秒换一次画面**，镜头别停太久 |
| **转折/证据** | 70–90% | 给出可信证据（设备、单据、现场、他人反应） |
| **收口** | 最后 10% | 一句行动号召 + 画面收住（不要话没说完就切） |

### 2.3 我们的落地清单

| # | 动作 | 现状 |
| --- | --- | --- |
| 1 | 分镜按**钩子/展开/证据/号召**四拍排（已有 beat 概念） | ✅ 部分（有 beat 字段） |
| 2 | **每镜时长上限**（≤6 秒，避免长镜头拖节奏） | ✅ 官方单次 4~12 秒、产品按 4 秒切 |
| 3 | **镜头时长下限**（<2 秒的碎片合并） | ❌ 未做 |
| 4 | **前景手部/工具入画**（POV 的代入感来源） | ❌ 提示词里没要求 |
| 5 | **现场声**（不要只有配乐或纯人声） | ❌ 未做（厂商出片自带环境声，但没约束） |
| 6 | **同一场次同一光线**写进每镜 | ✅ 一致性条款里已含"同一光线方向/色调" |

## 三、影视后期怎么做

### 3.1 五个环节

| 环节 | 内容 | 行业基准 |
| --- | --- | --- |
| **剪辑** | 粗剪（按脚本排）→ 精剪（去废话、调节奏）→ 定剪 | **每个镜头都要"有用"**：推进信息或情绪，否则删 |
| **调色** | 一级校正（曝光/白平衡统一）→ 二级（肤色、风格化）→ 统一 LUT | 先**统一**再风格化；跨镜色调不统一是 AI 片最大的"廉价感"来源 |
| **声音** | 对白 → 环境声 → 音效 → 配乐 → 混音（响度归一） | 对白优先；**响度目标 -16 LUFS 左右**（短视频平台） |
| **字幕** | 逐句、无标点、每行 ≤12 字、每屏 ≤2 行、位置固定 | 我们已实现（11 字/行、2 行、去标点） |
| **包装** | 片头/片尾、角标、转场 | 转场宁短勿长（0.2~0.5 秒），AI 片尤其不要花哨转场 |

### 3.2 节奏法则（三条）

1. **信息密度**：观众注意力以"秒"计；同一画面停留过长就掉留存 → **每 3~8 秒给一个新信息**；
2. **张弛**：快慢交替（快切 3 镜 + 一个长镜头呼吸），全程快切会疲劳；
3. **卡点**：剪切点落在**动作转折**或**语气重音**上，而不是等长切。

### 3.3 我们的落地清单

| # | 动作 | 现状 |
| --- | --- | --- |
| 1 | 调色统一（对比度/饱和度） | ✅ `eq=contrast=1.06:saturation=1.04` |
| 2 | 响度归一 | ✅ `loudnorm I=-16:TP=-1.5:LRA=11` |
| 3 | 接缝暗场（0.18 秒淡入淡出） | ✅ |
| 4 | 片尾收口（最后 0.4 秒淡出） | ✅ 今晚补的 |
| 5 | 字幕逐句、无标点、行宽受控 | ✅ 今晚补的 |
| 6 | **一级校正（跨镜曝光/白平衡对齐）** | ❌ 只做了全局 eq，没做逐镜对齐 |
| 7 | **卡点剪切**（按台词重音切） | ❌ 现在是等长 4 秒切 |
| 8 | **BGM + 音效层** | ❌ 完全没有 |
| 9 | **片头 0.5 秒黑场 / 片尾卡** | ❌ 未做 |
| 10 | **画面畸变自检**（手指、文字乱码） | ❌ 未做 |

## 四、立刻可做的（按性价比排序）

1. **参考图校验 + 提示**（边长/宽高比/张数语义）—— 我们已经在厂商那撞了两次 400，用户上传时就能拦住；
2. **三视图自动切分**（拼图 → 3 张）—— 直接解决"画面被参考图锁死"这个最影响观感的问题；
3. **内容创作视频路径补固定 seed** —— 跨镜一致性再上一层；
4. **人物锚写进每镜提示词**（年龄+发型+1~2 特征）；
5. **逐镜一级校色**（曝光/白平衡对齐）—— AI 片"廉价感"的主要来源；
6. **镜头时长下限 + 卡点剪切**；
7. **BGM/音效层 + 片头片尾**；
8. **画面畸变自检**（抽帧检查手部与文字）。
