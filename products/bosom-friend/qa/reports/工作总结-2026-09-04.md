# Bosom Friend 工作总结（截至 2026-09-04）

## 一、总体结论

桌面版从 0.2.0 一路升级到 **0.2.7**，核心问题（LOGO、内核握手、版本显示、删除、批量删除、退出行为）已全部修复并在真实桌面窗口逐项复验。测试方法也从“手摸”升级为“全量门禁 + 一致性闸门 + S 级页面验收”，同类问题不会再漏过。

## 二、本轮解决的主要问题

| 问题 | 根因 | 修复与版本 |
| --- | --- | --- |
| 测试不可信（网页当桌面测、0 用例报成功） | 测试脚本错把外部浏览器当桌面壳 | 改为驱动已安装 Electron 窗口；0 用例强制失败；web-first 断言 |
| 桌面 LOGO 是 Electron 默认图标 | 打包配置没写 icon | 品牌 LOGO 多尺寸接入，桌面/开始菜单/托盘/任务栏统一（0.2.1） |
| 内核握手失败（config file not found） | 启动器新旧版本混装，新版引用未打包配置 | 统一单一来源、重打包内核、加一致性闸门（0.2.2） |
| 系统版本显示 0.13.9 | 前端写死回退版本，桌面壳未注入版本 | 桌面壳成为版本权威，preload 注入；前端回退改为构建期注入（0.2.2） |
| 4 类架构红灯（挂 DSH Web UI、直连模型、依赖违规） | 遗留 Web 产物与直连兜底 | 退役 Web CLI 与直连原型；AI 一律经官方 DSH 内核；错误脱敏（0.2.3） |
| 内容创作记录删不掉（单条） | 记录 ID 缺失时假报“已删除” | 空 ID 如实报错；素材组计数按真实数据计算（0.2.4） |
| 批量删除不好使 | 后端静默保留被引用媒体；且内核运行时升级后不刷新 | 级联删除整个创作簇（0.2.5）；版本戳重解压内核（0.2.6） |
| 桌面 LOGO 仍没换 + 退出只有一种 | 图标缓存按旧路径不刷新；关闭窗口直接全退 | 快捷方式改指向独立品牌 ico + 刷新缓存；关闭窗口=托盘保留进程、托盘菜单“完全退出”（0.2.7） |
