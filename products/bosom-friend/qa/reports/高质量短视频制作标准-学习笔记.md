# 高质量短视频制作标准（学习笔记 → 产品落地）

> 来源：阿里云官方《视频生成 Prompt 指南》、日本 GOKKO 竖屏方法论（累计播放 100 亿次）、Seedance 一致性实测长文、蝉妈妈抖音百万播放数据、《抖音社区自律公约》与《创作者"诱导第三方"实施细则》。

## 一、AI 视频提示词（阿里云官方公式）

**基础**：`主体 + 场景 + 运动`
**进阶**：`主体（描述）+ 场景（描述）+ 运动（描述）+ 美学控制 + 风格化`
**图生视频**：`运动 + 运镜`（主体/场景/风格已由参考图确定）
**多镜头**：`总体描述 + 镜头序号 + 时间戳 + 分镜内容`

**美学控制六要素**（官方点名）：**光源、光线环境、景别、视角、镜头、运镜**。

**声音公式**（最关键的一条）：
`人声 = 说话内容 + 情绪 + 语调 + 语速 + 音色 + 口音`
`音效 = 音源材质 + 行为 + 环境音`
`BGM = 配乐 + 风格`
→ 我们此前只写了"用画外音说出这句话"，**没写音色**，厂商就默认配了男声。

## 二、竖屏拍摄（GOKKO，100 亿次播放）

- **竖屏左右极窄**：不要横排并站；用"前-后"纵深（肩后视角、人物朝镜头走近）
- **接写（特写）最适合竖屏**：脸部或手部充满画面，微表情直接传递，背景可以少做
- **抛弃"起承转合"**：前 2 秒给事件/转折，状况说明后置
- **"1 秒让观众预测接下来 5 秒"**

## 三、开场与节奏（蝉妈妈百万播放数据）

- **用户平均 0.8 秒划走一个视频** —— 前三秒留不住人，后面根本没人看
- **四种高留存开场**：预期落差 / 直击痛点提问 / 视觉冲击先行 / 悬念引导
- **第 5~8 秒完成信息点铺垫，15 秒内完成第一个高潮**
- **从第 4 秒起必须加速**，不要拖沓
- 实操：**至少写 10 版开头**，看**前 3 秒流失率曲线**

## 四、一致性（Seedance 实测长文 + 我们的对照实验）

- 参考图**≤3 张**：正面 / 3-4 侧 / 侧面，**同一场次同一光线**；**拼贴图有害**
- 提示词把人物定义为**单一实体**；锁定年龄+发型+1~2 个识别特征；**避免模糊风格词**
- 漂移诱因：**手遮脸、快速转头、重复图案服装、光线变化**
- **厂商按参考图数量切模式**：1 张=keyframe（画面被锁死）、**≥3 张=reference（锁人不锁场景）**

## 五、后期（影视后期五环节）

| 环节 | 要点 |
| --- | --- |
| 剪辑 | 每个镜头都要"有用"；**每 2~3 秒给新信息**；剪切点落在动作转折或语气重音 |
| 调色 | **先逐镜一级校正（曝光/白平衡对齐）再风格化** —— 跨镜色调跳跃是 AI 片廉价感的主要来源 |
| 声音 | 对白优先 → 环境声 → 音效 → 配乐 → **响度归一 -16 LUFS** |
| 字幕 | 逐句、无标点、每行 ≤12 字、每屏 ≤2 行、位置固定 |
| 包装 | 转场宁短勿长；片尾收口 |

## 六、平台合规（抖音官方条款）

- **画面**：不得出现二维码、电话、车牌、水印、第三方 logo、招牌/证书/制度牌文字
- **文案**：极限词、刺激消费、诱导点击、医疗承诺、联系方式、**谐音变体**全部禁止
- **站内私信引导也违规**（"私信我""评论区扣1"）
- **AI 生成内容需标注**
- 处罚阶梯：减少曝光 → 关闭商品分享 → 扣违约金 → 限制/永久封禁

## 七、拉片方法（用于验收自己的片子）

**拉片表字段**：镜号 | 画面 | 景别 | 时长 | 内容 | 备注
**每次出片按表逐镜记录**，再对照"高标准片子"找差距：
1. 开场前 3 秒能不能留住人
2. 每镜是否推进了信息（有没有废镜）
3. 跨镜色调/人物/声音是否一致
4. 字幕与画面是否对得上
5. 有没有违规元素
