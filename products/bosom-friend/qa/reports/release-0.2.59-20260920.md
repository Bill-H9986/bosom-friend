## 二、本版内容

| 主题 | 说明 |
| --- | --- |
| **融合创作：数字人口播 + 文生视频 B-roll** | 口播长视频不再"全是人脸"：分镜层要求一定比例的非口播镜，产品侧在一镜 B-roll 都没有时兜底改写（只改画面、不动台词）。真机实测 19 镜 = 8 口播 + 7 产品 + 3 空镜，画面里出现了工位、整机与拆装特写 |
| **长视频「字数门槛」前置 + 卖点上限 800** | 页面上直接告诉用户"这条片要 N 字口播稿、你已填 M 字"；输入框上限 200 → 800（DEF-108 / DEF-114） |
| **模型自述混进正文的闸门** | 写稿模型把自己的说明写进稿子时（"模型接口连续两次调用失败…下面这版是成品"）如实失败，不再让这些字被当台词念出来（实测曾出过 1084 字 / 目标 90 秒的怪片） |
| **内容创作时长档位显示与提交一致** | 界面显示的档位就是提交的时长（DEF-112） |
| **门禁假红修复** | 档位断言写死导致的假红（DEF-115） |
| **知识库检索修复（P1）** | 原先按写入顺序只扫前 400 篇，知识库 466 篇时**新写的笔记永远不会被检索到**且不报错（DEF-118）；改成按相关性粗排后再在预算内精排 |
| **更新检查（最小版）** | 设置页「系统与更新 → 开发者选项」可改版本清单地址、检查更新、打开下载页；桌面壳新增 `update-check.cjs` 与三条 `bosom-update:*` IPC（DEF-119 的接线部分）。**不含静默下载安装**（按产品口径不做） |

### 两条 P2 的规避说明（R5 要求）

- **DEF-113**：成片时长按"稿件字数 ÷ 音色语速"折算，与目标档位可能相差 10%~30%。规避：把目标时长当选片区间而非精确值；下版按实测语速回算字数。
- **DEF-117**：服务/场地类题材在没有参考素材时，画面是厂商按题材生成的**通用**素材（不是真实场地）。规避：这类题材先上传现场照片或走"场景呈现 + 参考图"；下版做题材参考图与素材位。
