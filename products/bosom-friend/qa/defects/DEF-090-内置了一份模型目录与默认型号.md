# DEF-090：产品内置了一份大模型目录与默认型号——用户没配，系统替他挑

> 编号：DEF-090（唯一、终身不变）
> 状态：Fixed
> 严重度：P1　　优先级：高（用户看不到自己"实际在用哪个模型"，也无从判断费用与效果）
> 缺陷类型：功能/诚实性
> 关联需求：REQ-005（模型配置）、REQ-022（长视频创作）
> 报告人 / 日期 / 环境版本：用户口头报障（"整个 APP 只内置 Agnes AI 服务商！但是不要内置任何大模型！所有内容创作中在设置里配置大模型就有选项！没有配置大模型就给提示！"）/ 2026-09-17 / 0.13.9
> 责任人 / 计划版本：Jay / 0.13.10
> 重开次数：0

## 复现步骤

1. 全新数据根启动产品（不填任何模型配置）；
2. 打开「设置 → 配置大模型」：内置 Agnes 卡里已经有一份 8 个模型的目录；
3. 只填 API Key 保存；
4. 打开「内容创作」：视频模型下拉里摆着两个 Agnes 型号（含"内置"标记），图片模型里还多一条本地排版模板；
5. 打开「长视频创作」直接生成：写稿用的是我们替他挑的 `agnes-2.5-flash`。

## 期望结果 vs 实际结果

- 期望：产品只内置**服务商**（Agnes 的地址与协议）；用哪个型号由用户在设置里填（可从服务商读回真实清单）；
  设置里没配，内容创作就不该有任何模型可选，而要明确提示"去设置里配置"。
- 实际：三处都在替用户决定模型——
  1. 设置页内置卡预置一份写死的模型目录（`AGNES_MODELS`：4 对话 + 2 图片 + 2 视频），并把它当成"他能用的清单"；
  2. 只填 Key 保存时自动补上 `model/imageModel/videoModel` 三个官方默认型号；
  3. 内容创作的模型清单 = 配置的那个 + **全部内置型号**，本地排版模板（`zy-template-image`）也当成一个模型摆着。

## 影响范围与发生频率

每一个用户、每一条生成路径。设置页自己写着"系统不内置任何大模型"，代码却在三处内置了模型——
用户按界面理解自己的用量与费用，实际上发出去的是我们挑的型号。

## 根因分析（5-Why）

- 直接原因：模型目录、默认型号、候选清单三处都是**产品侧写死的常量**。
- 为什么 1：把"内置服务商"（地址与协议，产品确实该内置）与"内置模型"（用哪个型号，用户的事）当成了同一件事。
- 为什么 2：默认型号最初是"为了用户只填一个 Key 就能用"的便利设计，但它的代价是
  **界面上显示的选择与实际发出去的型号可以不一致**——这类不一致在本项目里反复出现（DEF-087 是同一类）。
- 为什么 3：厂商拒权（401/403）时"换一个内置型号再试"看起来是韧性，实际是替用户改了配置，
  且只写进日志与生成记录，用户不会知道。
- 为什么 4：验收口径只管"配了能不能用"，没有一条管"没配时应该发生什么"。
- 根本原因归类：**把"我们挑的默认值"当成了"用户的配置"**。

## 修复方案（改根因）

1. `agnes.ts` 删掉模型目录与默认型号（`AGNES_MODELS`/`AGNES_DEFAULT_*`/`agnesCatalogModels`/
   `agnesModelOptions`/`agnesBuiltinConfig`），只留**参数契约**（档位、画幅、时长、素材上限）——
   它描述的是"用户配了某个 Agnes 型号时请求怎么发"，不是"产品提供哪些型号"；
2. `parseLlmOverride` 不再补默认型号：只填 Key 就是"服务商配好了、型号还没选"；
3. 设置页内置卡：接口地址仍由内置规格补齐，**模型目录从空开始**（用户点「获取可用模型」读回真实清单再勾选）；
4. 内容创作的模型清单 = **用户配置的那一个**（图片/视频各一个）；没配就是空清单；
   本地排版/幻灯片兜底不再冒充模型（能力保留为"厂商失败时的降级"，如实标注）；
5. 生成时不再"换一个内置型号再试"：只试用户配的那个；被拒就如实回原因，并在文案里指路设置页；
6. 界面上"没配模型"这件事有三处提示：对话（引导回复）、写稿/分镜（`missingChatModelReason`）、
   内容创作的模型下拉（空状态 + 「去设置里配置模型」按钮）。

## 回归用例

- `agnes.spec.ts`：只填 Key 时不补任何型号；填了就原样使用；对话模型清单 = 用户配的那些（没配为空）；
  内置卡回读的模型目录为空；未配型号时提示里带着"去哪配"；
- `content-params.spec.ts`：夹具先配好型号，再断言图片与视频档位一致（否则空清单会让断言空转）；
- `long-video.spec.ts`：模型清单只列配置的那个、不含本地模板。
