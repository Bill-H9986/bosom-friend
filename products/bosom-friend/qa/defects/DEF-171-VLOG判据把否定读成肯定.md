# DEF-171 VLOG 判据把「不是同一个人」读成「同一个人」：毒丸对照因此假绿

| 项 | 值 |
| --- | --- |
| 编号 | DEF-171 |
| 发现日期 | 2026-09-23 |
| 发现方式 | 判据复算（`qa/probes/verify-vlog-consistency.mjs --reuse` 复用同一批成片重判）——门禁「VLOG 跨镜一致性」要进三连绿之前先让判据自己站住 |
| 严重级 | P1（判据假绿：真的跨镜换人时这条检查照样判绿。它是"跨镜不换人"唯一的产品级证据，白设等于没设） |
| 状态 | Fixed（2026-09-23：先认否定式 + 五票满四票 + 同域真值对 + 429 重试 + `--reuse` 复算） |

## 现象（实测证据）

同一批成片（`qa/evidence/vlog-consistency-2026-09-23T14-54-46`）复算时，判官的原始回答是「不是同一个人」，
探针读出来的结论却是：

```
判官自检：A1 首帧 vs A1 中段 = 同一个人；A1 vs 陌生人 = 同一个人
VLOG_CONSISTENCY SKIP 判官把成片首帧和陌生人判成了「同一个人」——判官见谁都答同一个人，不可信
```

这一对的画面（`.small-A1.jpg` / `.small-stranger.jpg`，都在证据目录里）：

| 图 | 画面 |
| --- | --- |
| A1 成片首帧 | 二十多岁的年轻女士，米白针织衫，走在林荫步道上 |
| 陌生人（图片模型实出） | 三十五岁上下的男性，寸头、方脸、黑色夹克、纯灰背景 |

性别、年龄、服装、背景全不同，判官不可能答"同一个人"——错在**解析**，不在判官。

## 根因

判据解析先认肯定式、后认否定式：

```js
const verdict = VERDICTS.find(item => answer.includes(item))   // VERDICTS = ['同一个人', '不是同一个人', '看不清']
```

`'不是同一个人'.includes('同一个人')` 为真，否定答案因此先命中肯定项，一律被读成"同一个人"。
这个坑原代码里是显式写明的（用字面量数组把 `'不是同一个人'` 排在前面），改成 `VERDICTS.find` 复用常量时踩了回去。

后果方向是**假绿**：A 条跨镜真的换了人时，判官答"不是同一个人"也会被读成"同一个人"，门禁照样判绿。
抓住它的是**毒丸对照本身**（自检把"陌生人被判成同一个人"拦下并转 SKIP），这一轮没有把假绿放出去——
但如果没有毒丸对，这条判据就是摆设。

## 处置

| 改动 | 说明 |
| --- | --- |
| 先认否定式 | `answer.includes('不是同一个人')` 优先，再认肯定式与"看不清" |
| 五票满四票 | 作数门槛从"三票一致"提到 5 票里满 4 票（三票一致时仍出现过 2:1 翻盘） |
| 同域真值对 | 真值对从"形象图 vs 成片首帧"（两个画风域，实测 1:2 与 2:1 都出现过）换成 A1 首帧 vs A1 中段帧；跨域那对降级为记录项 `avatarAnchor`，不参与准入 |
| 429 重试 | 判官单次调用遇 429/5xx 等 15 秒重试（≤8 次）、每票间隔 5 秒——免费档速率限制是每分钟级的，实测连打十几票后整段判定被 429 打断（探针只能 SKIP，门禁转黄） |
| `--reuse` | 判据改动后只重判那次留下的成片，不再花一次厂商额度；复算路径本身也是这次取证的手段 |
| 采样量 15 取 10 | 门禁第二轮（2026-09-24，`gate-20260924-005518.md`）在同镜真值对上 5 票 3 是 2 否 → 探针如实 SKIP、判黄。标定四种问法各 5 票：判官单票错误率约 1/5 且**方向单一**（毒丸对跨配置 **15/15 全对**，从不对明显不同的人说「是」），失败模式是「判不了」而不是判错。于是把采样提到 **15 取 10**（满 10 票提前收工、`temperature=0`、票间隔 3 秒）：单次比较的「判不了」从约 26% 降到约 3%，而假绿门槛反而更高（要 15 票里 10 票把明显不同的人说成同一个）——**判据一个字没放宽** |


**负向对照（同一份证据）**：改回 `VERDICTS.find` 的写法，同一批成片立刻回到"陌生人被判成同一个人"的假绿——
同一份输入、只差一行解析，结论从假绿变正确。

**采样量复判（同一份成片，2026-09-24）**：那份被 5 取 4 判成「判不了」的第二轮证据，
在 15 取 10 下四个比较全部给出结论且方向正确 → `VLOG_CONSISTENCY PASS checks=4 fail=0`。
