# DEF-178 数字人口播的长视频多数镜头是数字静音：声音交给本机合成，而厂商不知道哪句是要说的话

| 项 | 值 |
| --- | --- |
| 编号 | DEF-178 |
| 发现日期 | 2026-09-25 |
| 发现方式 | 逐镜核对成片音轨（把成片按镜切开后用 ffmpeg 量音频均值）：2026-09-25 一条一分钟 15 镜的成片里 14 镜是数字静音 |
| 严重级 | P1（"数字人口播"是长视频的核心承诺，成片没有声音等于交付物不成立；用户为此付了厂商额度） |
| 状态 | Fixed（2026-09-25：删掉本机配音链路，台词逐字进每一镜提示词；真实出片未验证，见「验证」） |

## 现象（实测）

2026-09-25，一条一分钟、15 镜的数字人口播成片，逐镜量音频均值：

| 镜数 | 音轨 | 音频均值 |
| --- | --- | --- |
| 14 镜 | 数字静音 | −63 ~ −85 dB |
| 1 镜 | 有声 | 正常——那一镜的台词被写进了提示词 |

也就是说：**只有提示词里明说"说这句话"的那一镜出了声**。其余 14 镜画面是对的、时长是对的、拼接也是成功的——任务写 success、成片能播，只有听才发现整条片子几乎无声。

## 影响

- 数字人口播（以及走动 VLOG / 口播短视频 / 开箱测评 / 步骤教程这几种出镜形式）的成片不可用：一条默认就该有数字人念白的片子，交付到手是默片；
- 失败方式**静默**：没有报错、没有降级提示，任务与记录都是"成功"，用户要自己听完才发现；
- 配音与字幕是同一份台词的两种呈现：本机合成的时长与厂商重新配音后的时长对不齐时，字幕时间轴跟着漂（与 DEF-131 / DEF-113 同族）。

## 根因

三层，缺一层都不会变成"默片"：

1. **声音被交给本机合成**：产品自己用 Edge TTS 合成台词、用 ffmpeg 按镜拼接、再贴到成片上（配音来源 / 音色目录 / 演绎风格 / 韵律 / 试听 / 克隆这一整条链路）；
2. **厂商不知道哪句是要说的话**：厂商按"你给的秒数"出片，提示词里没有"说出这句话"，它给的就是一段只有环境声的画面——数字静音。实测里唯一有声的那一镜，正是台词被写进提示词的那一镜；
3. **厂商还会对成片重新配音**（原生声音）：本机合成的那一版与它并不一致，所以本机配音的时长**不能当成片时长用**，字幕与长度跟着漂。

## 修复（2026-09-25）

1. **删掉整条本机配音链路**：`server/src/tts.ts`、`server/src/tts-provider.ts` 删除，`msedge-tts` 依赖从 `server/package.json` 移除；音色目录、演绎风格、韵律、试听、克隆、配音来源设置（前端 `VoiceProviderTab`、`api/voice/voiceProvider.api.ts`、`voices/:id/preview` 路由）一并删除；
2. **台词逐字进每一镜的提示词**：口播镜要求"请让画面里的人用自然的口语说出下面这句话…"；产品镜与空镜"用画外音（旁白）说出这句话：…"——**旁白镜也不再有静音镜**；
3. **念法（persona）逐镜重复**：厂商按镜独立生成、镜间不共享状态，只在开头交代一次后面每一镜都拿不到（"同一个人声"靠这段描述逐镜重复保证）；不再把本机合成的音频当参考送进厂商——那会走厂商的"按参考音重新配音"，按参考音的节奏重念而不是按这句话本身；
4. **数字人形象改成「形象素材 + 念法 + 种子」**：形象素材是一张照片，或一段 2~12 秒的人像视频（服务端抽首帧当形象、另裁一段当厂商的参考视频）；念法只是写进提示词的描述，因此不存在"选了某条音色却出不来"的失败模式，也就不需要试听；
5. **媒体能力面不再承载语音合成**：`ctx.media` 只剩三个操作（`generateImage` / `submitVideo` / `pollVideo`），语音合成那一路从能力面与 Provider 一起删掉；
6. **语速收成产品口径 4.5 字/秒**：念法不再带"实测语速"，写稿字数下限与每一镜的出片时长按同一个数折算——不再有两套单位（DEF-113 的根因是同类）。

## 未做 / 边界

- **真实出片未验证**（余额不足）：画面是否每一镜都真的有人声，要靠成片音轨逐镜核对；
- **念法的声音一致性未实测**：厂商按提示词描述选声，"跨镜同一种声音"目前只有"同一段描述逐镜重复"这一条机制级保证；
- **视频建的形象（抽首帧 + 裁 2~12 秒参考视频）既没有真实出片验证、也没有用例覆盖**：参考视频走厂商的 video-to-video 通道，目前只有代码级证据（`server/test/functional` 里没有任何用例覆盖这条装配）；
- **历史数据的兼容**：老形象把旧音色与演绎风格折成一段念法描述（`personaPrompt(persona, legacyVoice, legacyStyle)`），折叠后的实际听感没有实测。
