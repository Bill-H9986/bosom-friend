# DEF-099：生成参数区拥挤——「画面字幕」紧贴在档位按钮底下（用户报障截图）

> 关联需求：REQ-022（长视频创作）

## 复现步骤

1. 打开长视频创作页，看「③ 生成参数」；
2. 「目标时长」「画幅」两组按钮下面**紧贴着**「画面字幕」标签（几乎没有间隙），
   看起来像"5 分钟"按钮的文字说明，而不是另一项独立设置。

## 期望结果 vs 实际结果

- 期望：三组控件各有各的分组间距；"开关 + 一句说明"这类控件与"选一个档位"的按钮组明显分开。
- 实际：档位按钮下方 0 间隙就是下一个标签。

## 根因分析

- 上一轮（DEF-095）把参数区拆成四段时，**「画面字幕」那一块被留在了 ③ 段容器之外**：
  它成了 ③ 段的兄弟节点，于是既拿不到容器的纵向间距（space-y / gap-y），也没有自己的 mt。
- 这类"搬动段落时漏掉一个兄弟节点"的排版事故，DOM 上看不出来（页面照样渲染），
  只有肉眼看截图才发现——上一轮的验证只截了长视频页全景，没有逐段核对间距。
- 根本原因归类：**重排时用"看起来对"代替了"逐段核对结构"**。

## 修复方案

1. 「画面字幕」搬回 ③ 生成参数容器内，作为独立一项（自带分隔线 border-t + pt-4），与上面两组档位按钮分开；
2. ③ 段容器由横排 flex（gap-x-8 / gap-y-5）改为 space-y-6 外层 + 内层横排 flex（gap-x-10 / gap-y-5）：
   横向留给两组档位，纵向由容器统一给间距；
3. 标签与控件的间距 gap-1.5 → gap-2，段间距 mt-6 / pt-5 → mt-7 / pt-6。
