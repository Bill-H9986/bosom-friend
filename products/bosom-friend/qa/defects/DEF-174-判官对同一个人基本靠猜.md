# DEF-174 VLOG 判据的判官对「同一个人」基本靠猜：四种问法在判据对上都是掷硬币

| 项 | 值 |
| --- | --- |
| 编号 | DEF-174 |
| 发现日期 | 2026-09-24 |
| 发现方式 | 三连绿的 5 次尝试里 3 次黄在这条检查上（`gate-20260924-005518` / `070628` / `084906`）；把同一批真机成片拿出来做逐问法标定 |
| 严重级 | P2（不影响产品功能，但它让「跨镜不换人」这条验收无法可靠判定：门禁要么判黄、要么靠运气判绿） |
| 状态 | Open（改法两条见下；今晚共 5 次尝试 14 轮门禁，其中 9 轮 46 绿 0 红 0 黄，其余 5 轮有 4 轮卡在这条） |

## 实测（同一批真机成片，每种问法 9~15 票）

| 问法 | 判据对 A1↔A2（应=同一个人） | 毒丸对 A1↔陌生人（应=不是同一个人） |
| --- | --- | --- |
| 裸问句（三选一） | 12/15 | 15/15 |
| 先说特征再结论（CoT） | 9/15 | 15/15 |
| 是 / 否 强制二选一 | 5 是 / 4 否 | 9/9 否 |
| A / B 强制二选一 | 4 A / 5 B | 9/9 B |
| 推理模型 `agnes-2.5-pro` + CoT | **9/9** | **8/8** —— 但**账户余额耗尽用不了**（403 预扣费失败：剩余 ￥0.004310 / 每次约 ￥0.005180） |

**结论**：免费档判官对「同一个人、不同背景与姿态」这一对的判别接近随机（四种问法 45%~80%），
而对「明显不同的人」是 100% 正确。也就是说它抓得住「换人了」这种粗错，**判不了「没换人」**——
而 A 条（固定种子）要的正是后者。之前判绿的几轮是运气，不是判据可靠。

现场还有两种具体表现（都进了门禁报告）：

- 判官把同一对描述对了却给了不在答案集里的结论：「图1：年轻亚洲女性…黑色长直发和白色圆领毛衣。
  图2：年轻亚洲女性…同款白色圆领毛衣。是两个人」——探针按「没给三个答案之一」记 SKIP（不判红，这个方向是对的）；
- 判官调用被 429/连接超时打断，靠 15 秒重试硬扛。

## 决定（2026-09-24，产品负责人拍板）

**在判官换成可靠模型之前，这条检查按「证据项」处理、不参与准出**（准则 §7 判据修订记录有完整条目：
改了什么 / 为什么 / 影响面 / 退出条件）。单轮门禁里它仍然如实记绿/黄/红，只是黄灯不再阻塞发布；
`run-gate-triple.mjs` 的 `EVIDENCE_ONLY_CHECKS` 与门禁报告里的「（证据项）」后缀都是这个决定的留痕。

**影响面照实写**：「跨镜不换人」从此没有准入级证据，只剩机制级证据（每镜同一张形象图 + 固定种子，
单测覆盖）+ 每轮的判官记录（成片首帧与 PASS/SKIP/FAIL 明细）。
**退出条件**：判官换成可靠模型（或本机人脸特征比对）后，必须把它从证据项清单里删掉、恢复为准出判据。

## 改法（两条，仍需实施）

1. **给厂商账户充值**，把判身份换成 `agnes-2.5-pro`：探针已留 `--judge-model` 开关，实测 9/9 与 8/8；
2. 或**本机确定性比对**：本地人脸特征（不依赖第三方模型的逐次判定）。正负对照可以直接用现有证据目录里的
   图对（`qa/evidence/vlog-consistency-*/.small-*.jpg`）校准阈值——这条更彻底，代价是引入一个人脸嵌入依赖。

在此之前，这条检查的作用应当**如实重述**：它能证明「厂商没有明显换人」，不能证明「跨镜确实是同一个人」。
