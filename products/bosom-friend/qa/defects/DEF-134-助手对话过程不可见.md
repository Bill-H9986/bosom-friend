# DEF-134 助手对话的过程不可见：内核在调工具，界面只等到"一下蹦出答案"或一句失败

| 项 | 值 |
| --- | --- |
| 编号 | DEF-134 |
| 发现日期 | 2026-09-22 |
| 发现方式 | 用户反馈"我的任务里要么失败、要么一下蹦出答案，不要只有两种状态" → 探真实内核会话的事件流 + 读任务落盘 |
| 严重级 | P1（每条助手对话都命中；用户看不到它在做什么，也无法判断卡在哪一步） |
| 状态 | Fixed（2026-09-22：过程事件实时上界面并落盘；正文按模型时间戳回放成逐字出现） |

## 现象（实测证据）

2026-09-22 用官方 SDK 客户端跑一次真实内核会话（问题："现在产品里有几个平台账号？请调用工具查一下再回答"），
收到的通知种类：

```
session.event :: tool/call      ×2      ← 模型真的在调产品工具
session.event :: tool/result    ×2      ← 工具真的返回了数据
session.event :: assistant/message ×2   ← 正文只在回合结束出现
session.event :: assistant/chunk  ×0    ← 一条都没有
```

而任务记录（`agent-tasks.json`）里那条对话只有：`user,assistant,user,assistant…`
——**中间那两次工具调用与结果一个字都没留**。用户看到的因此只有两种状态：
转圈然后整段出现（`assistant/message` 一次性到达），或者一句
`大模型调用失败：未知错误`（实测任务 `task-b4821916` 的第 12 轮）。

正文为什么是"蹦出来"的：厂商网关（agnes，openai-completions）**不发 `assistant/chunk` 的 text-delta**，
正文只在回合结束的 `assistant/message` 里（这一点 DEF-072 已经记录过）。
但那条消息里带着**模型自己的增量时间戳**（Session v2 的 `stream` 字段：`text-chunks` 的 `time0` + `dt[]`），
产品此前把它整条丢掉。

## 根因

**内核客户端只挑正文，其余事件全部丢弃；服务端只转发正文、只落盘正文。**

1. `kernel-client.ts` 的接收循环只认 `assistantTextOf`（增量）与 `assistantMessageTextOf`（整段），
   `tool/call` / `tool/result` / 带时间的 `stream` 都落在`continue`之外被忽略。
2. 服务端的 SSE 通道只发 `init` / `stream_event(text_delta)` / `result` / `done`，
   任务消息只 push `user` 与最后那条 `assistant`。
3. 前端其实**早就支持**工作流渲染（`convertMessages` 会把 `stream_event` 的 tool_use 还原成
   `workflowSteps`，`ChatMessage/WorkflowSection` 会画出来）——缺的只是服务端把事件送过来。

## 修复（2026-09-22）

1. `kernel-client.ts` 新增三个纯函数读法 + 两个读法：`toolCallOf` / `toolResultOf` /
   `assistantStreamPartsOf`（带时间增量）与 `KernelAgentStep` 回调；`assistantStreamPartsOf`
   只认正文（`text-chunks` / 裸 `text-delta`），推理增量不算正文。
2. 服务端把工具调用/结果按**前端既有的事件形状**转发（`stream_event` + `content_block_start(tool_use)`、
   `content_block_delta(input_json_delta)`、`user` + `tool_result`），并**边跑边落盘**到任务消息——
   右侧助手实时看到每一步，"我的任务"回看时能重放整条过程（前端零改动）。
3. `replayFrames`：正文在增量通道为空时按模型真实时间戳回放，总预算 2.5 秒、单帧上限 120ms、
   最多 120 帧，**文本与顺序一字不改**（不是打字机动画，是模型自己的出字节奏被压缩等待）。
4. 右侧助手面板渲染过程栏（`data-testid="ai-assistant-steps"`）+ 共享工具中文标签
   （`bosom_platform_list_accounts` → "查平台账号"，`components/Chat/utils/toolLabels.ts`）。
