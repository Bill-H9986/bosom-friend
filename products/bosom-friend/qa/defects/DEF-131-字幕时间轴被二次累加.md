# DEF-131 字幕比口播晚一整句：绝对时间轴被当成"相对本镜"又平移了一次，末尾十几条落在成片之外

| 项 | 值 |
| --- | --- |
| 编号 | DEF-131 |
| 发现日期 | 2026-09-22 |
| 发现方式 | 用户反馈"字幕与口播说话时不匹配" → 读成片同目录的 `long-video-subs.ass` 逐条对时间轴 + 用 ffprobe 量成片与各镜真实时长 |
| 严重级 | P1（每条带字幕的长视频都命中，字幕是这类片子的主要信息通道） |
| 状态 | Fixed（2026-09-22：拼接层只烧字幕、不挪时间轴；新增越界判据） |

## 现象（实测证据）

用户那条 90 秒数字人口播片（任务 `lv-3796e8f1`，18 镜，成片 `lv-lv-3796e8f1.mp4`）：

| 层 | 值 | 证据 |
| --- | --- | --- |
| 成片真实时长 | **80.54 秒** | `ffmpeg -i lv-lv-3796e8f1.mp4` |
| 各镜成片真实时长 | 4.48 / 4.13 / 4.48 / 4.96 / …（共 80.66 秒） | 逐镜 ffmpeg（与拼接层探测同一口径） |
| 字幕里第 1 条 | 0.00 → 4.48 秒 | `uploads/long-video-subs.ass` |
| 字幕里第 2 条 | **8.96** → 13.09 秒 | 同上（第 1 镜 4.48 秒就结束了，字幕却等到 8.96 秒才出现） |
| 字幕里最后一条 | 152.36 → **156.84** 秒 | 成片只有 80.54 秒——这条字幕永远看不到 |

规律一眼可见：第 n 条字幕的起点 = 前 n 镜时长之和 **× 2**。用户看到的是**字幕永远比口播晚一整句**
（第 1 镜的画面配第 0 镜的字幕），后半段干脆没有字幕——也就是"字幕与口播说话时不匹配"。

## 根因

**同一份时间轴被累加了两次。**

1. 编排层按各镜真实时长累加出**绝对**时间轴（`long-video.ts` 的 `buildSubtitleCuesFromDurations`）：
   第 2 条 = `[4.48, 8.61]`，这已经是成片时间轴上的秒数。
2. 拼接层又按"各镜起点"平移了一次（`video-compose.ts` 的 `alignCuesToTransitions(cues, segmentStarts(durations))`）：
   `4.48 + 4.48 = 8.96`。

而黑场过渡**不重叠**（淡出淡入各占本镜自己的时间，见 `DIP_SECONDS` 的注释），
所以"各镜时长累加"本来就是成片时间轴——这次平移是纯多余的，且是**加倍**而不是"挪一点"。

为什么没被测试抓住：当时的用例只断言调用方算出来的中间结果
（`composeCalls.at(-1).subtitles` 是绝对时间轴、首尾相接），**没有一条看着真正烧进画面的那份 ASS**。

## 为什么值得记

1. 字幕烧错**不会报错**：日志一切正常，用户拿到片子才发现"字幕对不上"——这类缺陷只能靠"读产物"抓；
2. 它是"两个地方各算一遍时间轴"的必然结果：一处算绝对、一处以为别人给的是相对；
3. 判据完全可以离线写死：**任何一条字幕都必须落在成片时长之内**——落到片子外面的字幕谁都看不到。

## 修复（2026-09-22）

1. **拼接层只烧字幕、不挪时间轴**：删掉 `alignCuesToTransitions` 与 `alignToTransitions` 选项，
   `ComposeOptions.subtitles` 的契约写明"秒数是成片时间轴上的绝对时间"；随之删除不再有调用方的
   `segmentStarts`。
2. **新增越界判据 `subtitleTimelineProblems(cues, filmSeconds)`**：时长非正 / 起点为负 /
   结束时间超出成片（容差 0.05 秒只吸收毫秒舍入），拼接前在日志里报出来（`[COMPOSE_ERR]`）。
   不因此判整条失败：画面与声音是对的，字幕错位是叠加层的问题，失败只会让用户拿不到片子。
3. **补上真正该有的回归用例**：`video-compose.spec.ts`「每镜的字幕窗口就是它那一镜的窗口」用**真 ffmpeg**
   拼两段，然后读回 `long-video-subs.ass` 里的 `Dialogue:` 行，断言第 2 条的起点 = 第 1 镜的时长
   （而不是它的两倍）。负向对照：把二次平移还原回去，这条用例判红，且 `[COMPOSE_ERR]` 同时报出
   「第 2 条字幕落到成片之外（8.04→12.06 秒，成片只有 8.04 秒）」。

## 回归判据

| 判据 | 用例 |
| --- | --- |
| 字幕窗口 = 所属镜头的窗口（读回烧进画面的 ASS） | `video-compose.spec.ts`「每镜的字幕窗口就是它那一镜的窗口」 |
| 越界/非正/负起点的字幕条被报出来 | `video-compose.spec.ts`「字幕落到成片之外时如实报出来」 |
| 一镜一条、换行只是排版折行 | `long-video.spec.ts`「一镜一条：台词里的换行只是剧本排版」 |
