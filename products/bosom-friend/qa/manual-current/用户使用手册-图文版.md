## 1. 快速上手：启动与主界面

### 1.1 启动 APP

在浏览器打开本机地址或双击桌面快捷方式后，应用会自动启动本地服务并进入主界面。首次冷启动需要初始化本机数据，通常会比后续启动稍慢；服务就绪前页面会提示「本地服务启动中，数据将在就绪后自动加载」。

### 1.2 主界面布局

![首页总览](manual-shots/01-home.png)

| 编号 | 区域 | 说明 |
|---|---|---|
| ① | 左侧导航栏 | 内容创作、AI互动、任务记录、发布日历、数据中心、全局监控、知识库 |
| ② | 开始创作 | 一键进入内容创作页面 |
| ③ | 添加频道 | 绑定小红书 / 抖音账号并打开频道管理 |
| ④ | 右侧 AI 助手 | 常驻面板，随时向 AI 提问（详见第 9 节） |
| ⑤ | Bosom Friend 客户端菜单 | 底部用户入口：联系我们 / 消息通知 / 设置 |

首页主标题为「Bosom Friend AI 内容创作营销系统」，面向零基础用户，核心链路是 AI 创作 → 草稿 → 多平台发布 → 数据复盘 → 自动接待。

## 2. 内容创作（草稿箱与素材库）

点击左侧「内容创作」进入。页面顶部两个标签：**创作 / 素材库**。

![内容创作主界面](manual-shots/10-draftbox.png)

| 编号 | 区域 | 说明 |
|---|---|---|
| ① | 创作 / 素材库 | 切换创作工作台与素材管理 |
| ② | 素材上传区 | 最多上传 1 段视频（≤180 秒）、1 个音频（≤180 秒）、9 张图片；提示词中输入 `@` 可引用素材 |
| ③ | 生成模式与参数 | 图文 / 视频模式、目标平台、模型、分辨率、比例、时长、数量、文案要求 |
| ④ | 一键发布 | 直接从当前内容发起发布流程 |
| ⑤ | 内容列表 | 全部 / 草稿 / 视频 / 图片，支持批量移动、批量删除、查看生成记录 |

### 2.1 AI 一句话生成草稿（核心流程）

1. 在提示词输入框描述需求，例如「写一条无人机培训招生文案，突出 CAAC 证书价值」；
2. 需要素材时先上传图片 / 视频 / 音频，并在提示词中用 `@` 引用；
3. 选择生成模式（图文或视频）、目标平台、模型与尺寸 / 比例 / 时长 / 数量；
4. 点击「生成草稿」，等待任务完成；
5. 结果出现在下方列表，点击卡片可预览、编辑、发布或继续生成。

### 2.2 素材库

AI 生成的图片、视频与手动物料会自动归档到「素材库」，支持按类型筛选、批量移动、批量删除与拖拽发布。

## 3. 一键发布到多个平台

在内容创作页右上角点击「一键发布」：

![一键发布弹窗](manual-shots/13-publish-dialog.png)

1. 弹窗内选择要发布的频道与账号；
2. 尚未绑定账号时，点击「添加频道」先去绑定（见第 4 节）；
3. 填写正文、标题、话题，并上传图片或视频；
4. 检查各账号的平台参数与校验提示；
5. 点击「下一步」进入发布确认，发布后可在「发布日历 / 数据中心」跟踪进度与数据。

> 说明：平台发送必须使用账号的真实登录态；没有登录或平台未返回作品链接时，系统会如实提示失败，不会标记为成功。

## 4. 绑定平台账号（频道）

在左下角点击「添加频道」，或进入频道管理后点击「连接新频道」：

![频道管理弹窗](manual-shots/58-channel-modal.png)

- 当前「连接新频道」列表开放 **小红书** 与 **抖音**；
- 点击平台卡片后，按页面提示用手机扫码或浏览器完成授权；
- 绑定成功后，账号会自动出现在「默认空间 / 我的频道」中；
- 已绑定账号自动纳入全局监控、数据采集与评论 / 私信读取；
- 可通过「新建分组」按业务划分账号，每个分组可独立展示与筛选。

> 页面内同时提供平台清单与其他平台的能力入口；实际能否授权、发布与采集以平台能力清单和当前登录态为准。

## 5. 全局监控与 7×24 自动接待

左侧导航点击「全局监控」：

![全局监控](manual-shots/50-accounts.png)

| 编号 | 区域 | 说明 |
|---|---|---|
| ① | 核心统计卡 | 绑定账号、在线账号、扫描评论、待前端确认 |
| ② | 引擎参数 | 轮询间隔、每账号每轮上限、去重窗口、失败重试冷却 |
| ③ | 7×24 全自动接待 | 开启后由前端智能体自动读取并发送待办；关闭时只采集登记 |
| ④ | 平台统一监控总览 | 各平台账号数、评论接待 / 私信接待状态 |
| ⑤ | 账号级接待状态 | 已接入、平台风控、未登录、待接入等真实状态 |

### 5.1 接待引擎边界

当前评论与私信读取覆盖 **抖音、小红书**：

- 引擎只做真实平台只读采集，命中规则的评论 / 私信会登记为「待前端确认」；
- 全自动模式由应用内的前端智能体触发发送；
- 关闭全自动模式时，需要你在「账号管理 → 评论接待 / 私信接待」中手动确认；
- 其他平台会明确显示「待接入 / 待官方插件」，不会伪造采集或发送结果。

### 5.2 账号管理与接待规则

顶部选择或搜索账号后，进入「接待规则」标签：

![账号管理标签](manual-shots/52-accounts-tab1.png)

![新建接待规则弹窗](manual-shots/59-rule-modal.png)

| 字段 | 说明 |
|---|---|
| 规则名称 | 自定义名称，便于识别 |
| 触发关键词 | 输入后回车添加；命中任一关键词或全部命中 |
| 排除词 | 命中任意排除词的访客消息不触发此规则 |
| 适用账号 / 平台 | 可限定为单个账号或全部平台 |
| 回复方式 | AI 智能生成（使用已配置大模型）或固定模板 |
| 客服人设 | 描述客服身份、语气与回复偏好 |
| 优先级 / 启用 | 数字越小越优先，可随时开关 |
| 失败重试冷却 | 失败后重新进入待办前需要等待的分钟数 |

可先点「推荐模板」一键套用 **报价咨询 / 合作洽谈 / 售后客服 / 新品促销**，也可用「测试接待」验证规则是否命中。

## 6. AI 互动：热点内容与评论搜索

左侧导航点击「AI互动」，上方包含 **热点内容 / 评论搜索** 两个标签。

### 6.1 热点内容

![热点内容](manual-shots/20-ai-interaction.png)

- 聚合 **微博、抖音、小红书、知乎、B站** 等平台榜单；
- 每条内容可打开原文、查看热度与详情；
- 结合右侧 AI 助手，可让 AI 总结热点并给出选题建议。

### 6.2 评论搜索

![评论搜索](manual-shots/22-ai-tab1.png)

- 按关键词搜索全网笔记，输入品牌词、产品名或评论高频词；
- 筛选内容形式（图文笔记 / 视频笔记）、作者类型（素人 / 腰部达人 / 头部达人）、笔记分类（美食、旅行、美妆等）、时间范围（7 天 / 15 天 / 30 天 / 自定义）；
- 支持综合排序、互动量、点赞、收藏、评论、分享、最新发布；
- 结果可查看原文、打开详情、加载更多，并可按当前条件导出 Excel。

## 7. 任务记录：AI 任务管理

左侧导航点击「任务记录」：

![我的任务](manual-shots/30-tasks.png)

- **全部任务**：列出 AI 对话、图文 / 视频生成与发布任务；
- 支持按标题搜索、收藏筛选与多种状态过滤；
- 点击任务卡片进入详情。

![任务详情](manual-shots/31-task-detail.png)

任务详情页可以看到 AI 的完整执行过程、工具调用、最终产出与发布动作卡，并支持 **收藏 / 分享 / 评分**。执行中的任务会实时流式输出；离开后可在任务记录中重新进入查看。

## 8. 知识库

左侧导航点击「知识库」（仅桌面端启用）：

![知识库](manual-shots/40-knowledge.png)

- 内置知识库随应用保存，包含平台发布指南、创作方法论、接待话术等；
- 左侧目录树与全库搜索；
- 中间支持 Markdown 编辑 / 预览，输入停止后自动保存；
- 笔记支持 `[[双链]]` 反向链接，形成网状知识结构；
- 右上角可新建笔记、挂载外部库，内置文档不可删除。

> 网页版未挂载 Electron IPC 时，知识库页面会提示「仅在桌面端可用」；桌面端打开后即可正常编辑。

## 9. 右侧 AI 助手

每个页面右侧都有常驻 **AI 助手面板**：

![AI 助手](manual-shots/60-chat.png)

- 直接输入需求：内容创作、热点选题、互动回复、发布建议都可以问；
- 三个快捷指令：
  - 帮我写一条抖音爆款文案
  - 为一款新品生成小红书种草笔记
  - 帮我总结今天的热点并给出选题
- 点「新对话」开始全新会话；应用重启后临时会话会清理，长期数据保存在「任务记录」中；
- 未配置自己的大模型 API 时，面板使用内置模板兜底并提示配置入口。

## 10. 设置中心

点击底部「Bosom Friend 客户端」→「设置」进入，共三个分区：

![通用设置](manual-shots/70-settings.png)

| 分区 | 功能 |
|---|---|
| 通用设置 | 个人资料（昵称、头像）、外观主题（浅色 / 深色 / 跟随系统）、界面语言 |
| 自定义大模型 | 配置多个 OpenAI 兼容模型服务（各自的 API Key 与模型列表）与图片 / 视频通道 |
| 系统与更新 | 当前版本、数据安全、产品信息、检查更新与匿名遥测（桌面端高级选项） |

### 10.1 自定义大模型（重要）

![自定义大模型](manual-shots/71-settings-llm.png)

系统不内置共享大模型 Key，完整 AI 能力需使用你自己的钥匙。这一页分两块：上面是「我的模型服务」列表，下面是当前选中服务的编辑区。

1. 点「添加模型服务」，在下方编辑区点击「去 Agnes AI 国内站领取钥匙」，在 `https://platform.agnes-ai.cn/` 注册并创建 API Key（按量计费）；
2. 填写 API 接口地址、你的 API Key、你的模型名称；
3. 不确定模型名时可点击「自动获取可用模型」，拉取到的模型点一下即可加入模型列表；
4. 点「保存并使用我的钥匙」立即生效；保存后模型以标签形式列在下方，点标签即可切换当前对话模型，无需重启；
5. 可以保存多个服务（例如 Agnes 与公司网关）：在列表里点「设为当前」切换全局生效的那一个，点垃圾桶图标（需再点一次「确认删除」）删除不需要的服务；删完最后一个即恢复内置模板模式；
6. 图片 / 视频模型为选填：同厂商可复用当前服务的 Key，其他厂商可分别填写接口、Key 与模型名。

> 🔒 安全说明：密钥保存在本机用户目录，不会随安装包分发；未配置时 AI 使用内置模板，不会伪造真实模型结果。

### 10.2 系统与更新

![系统与更新](manual-shots/73-settings-system.png)

- 当前版本：`v0.13.5`；
- 数据安全：服务仅绑定本机，数据保存在 `~/.bosom-friend/`，不主动上传云平台，启动时自动备份；
- 桌面端高级区：可配置更新服务器地址、立即检查更新、下载 / 安装新版本、匿名遥测开关；
- 浏览器网页版通常随产品交付自动更新，如需手动重新部署可参考部署文档。

## 11. 常见问题 FAQ

**Q1：AI 助手说没有配置大模型，怎么办？**
到「设置 → 自定义大模型」领取并填写你自己的 API Key 与模型名。未配置时系统使用内置模板，不会调用真实模型。

**Q2：当前支持绑定哪些平台？**
频道连接页当前开放小红书、抖音；数据中心提供更多平台筛选项，但实际授权、发布、采集与接待请以平台能力清单和登录态为准。

**Q3：为什么评论 / 私信没有自动发出？**
安全设计是「只读采集 + 前端显式发送」。引擎只登记待办；你要么打开全自动接待，要么在评论 / 私信接待页手动确认发送。

**Q4：绑定的账号安全吗？会不会被封？**
应用使用真实平台登录态，带轮询间隔、去重窗口、失败冷却与风控状态提示。请按平台规则正常量级使用，避免短时间内高频操作。

**Q5：数据存在哪里？**
账号、作品、任务、素材与知识库都保存在本机产品目录（`~/.bosom-friend/`），不与开发系统 DSH 混用，并有启动备份。

**Q6：如何升级版本？**
桌面端在「系统与更新」中检查更新并安装；网页版随产品交付更新。遇到页面数据异常时，先重启本机服务或恢复备份。

**Q7：知识库为什么打不开？**
知识库依赖桌面端本地文件能力。网页版提示不可用时，请使用 Windows 桌面端打开。
