## 实机中发现并修复（产品/脚本）

1. **兑换码 BOM 坑（数据层）**：.NET UTF8 写入带 BOM → 服务端 JSON.parse 回退空数组、兑换报“无效”。修正：运营发卡/种子统一走 Node 无 BOM 写入；同时把兑换判定从 `=== undefined` 放宽为 `== null`（兼容两种记录形态）。
2. **发布抽屉需要真实用户三步**（脚本已按实机路径补齐）：账号必须先添加 → 素材需先存在 → 发布前必须填「标题”——空标题时“发布”无任何反馈，这是产品设计事实，已在报告记录。
3. **账号创建后 UI store 不刷新**：hash 导航不重拉账号列表，需整页刷新——产品事实（已记入备注），实机脚本以 reload 模拟真实登录后重访。
4. **列表接口不含 messages**（详情才有）：任务消息断言改用 detail 接口；列表/详情职责分离为产品设计。
