## 缺陷：闲鱼声明支持扫码授权，但二维码接口 500

| 项 | 内容 |
| --- | --- |
| 现象 | 「添加频道」→ 闲鱼 → 显示「授权失败：二维码加载失败或已过期」 |
| 复现 | `GET /v2/channels/accounts/auth/xianyu?groupId=grp-default` 返回 200 并给出 sessionId；随后 `GET /platform-login/qr/<sid>` 返回 **HTTP 500** |
| 会话状态 | `{"code":50000,"message":"二维码加载失败或已过期，请点击重试重新获取二维码"}` |
| 根因 | 平台目录声明 `xianyu.capabilities.auth.supported = true`，但该平台未接入授权实现 |
| 与文档冲突 | `功能清单-三大核心功能.md` 写明「闲鱼尚未接通，只出现在添加频道并标注**即将支持**」，实际未标注且给出可用的扫码入口 |
| 建议 | 二选一：① 收敛平台目录，把未接入平台的 `auth.supported` 置为 false；② 按文档在「添加频道」里标注「即将支持」并禁用入口 |

## 附带发现：平台目录能力声明与实际接入不符

`GET /api/v2/channels/platforms` 声明 11 个平台 `auth+publish` 均受支持（含支付宝生活号/TikTok/微博/虎扑等），
但产品实际只接入 4~5 个。**接口在对外宣称尚未实现的能力**，属于「数据绝对真实」要治的一类问题。
