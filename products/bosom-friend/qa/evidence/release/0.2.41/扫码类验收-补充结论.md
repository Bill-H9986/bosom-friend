# 扫码类验收 · 补充结论（B1-04 / A4-09）

> 日期：2026-09-12  |  方式：安装版 0.2.41，Playwright 驱动真实前端（不使用接口绕过）

## B1-04 抖音小程序授权 —— 界面无入口

| 项 | 结果 |
| --- | --- |
| 检查路径 | 「添加频道」→「默认空间」→ 抖音 · XchanM520 卡片 |
| 卡片上的操作 | 仅 **刷新粉丝 / 切换 / 删除** 三个按钮 |
| 小程序授权入口 | **不存在** |
| 代码侧 | `api/platforms/douyin.api.ts` 有 `apiDouyinMiniAppChannelAuthComplete`（POST `plat/douyin/miniapp-auth/complete`），但界面上没有触发它的入口 |
| 相关说明 | `AuthLoadingPage.tsx` 的 `data-testid="cm-auth-douyin-miniapp-qr"` 命名有误导性：它是**所有扫码平台共用**的扫码界面（图标与文案均为动态），并非抖音独有 |
| 结论 | **该项在界面上不可验收**（无入口）。B1-03 已用小红书真机扫码证明该扫码路径可用 |

## 两项的合并结论

抖音小程序相关的两条验收准则（B1-04 抖音小程序授权、A4-09 扫码发布）在当前安装版的界面上**都没有入口**；
API 层存在对应能力（`douyin.api.ts` / `plat/douyin/miniapp-auth/complete`），但前端没有暴露触发路径。

建议二选一：
1. 补齐界面入口后重新验收；
2. 若本版不打算开放，把这两条准则标注为「本版未开放」，避免在功能清单里以「已实现待覆盖」长期挂账。
