# 闲鱼「授权失败」缺陷：修复与验证记录

> 日期：2026-09-12  |  修复提交：`80f6048`

## 缺陷现象（用户实测）

「添加频道」→ 点「闲鱼」→ 显示「授权失败：二维码加载失败或已过期，请点击重试」

## 根因链（逐层查实）

| 层 | 事实 |
| --- | --- |
| 接口 | `GET /platform-login/qr/<sid>` 返回 **HTTP 500** |
| 真实错误 | `BrowserType.launch: Executable doesn't exist at .../browsers/chromium_headless_shell-1169/chrome-win/headless_shell.exe` |
| 打包 | 安装包只带 `chromium-1208` 与 `chromium_headless_shell-1208`，**缺 1169** |
| 目录 | `xianyu_uploader` 模块存在 → 目录扫描判为 `available` |
| 白名单 | 闲鱼同时在 `PRODUCT_CHANNEL_PLATFORMS` 里 → `channel: true` → 前端当可连接频道展示 |
| 结果 | 用户点进去必然失败，且没有任何「即将支持」提示 |

## 修复

| 改动 | 内容 |
| --- | --- |
| `PRODUCT_CHANNEL_PLATFORMS` | 移除 `xianyu` |
| 新增 `ENGINE_PRESENT_BUT_NOT_READY` | 引擎有模块但产品未就绪的平台报 `coming_soon` |
| `status` 计算 | 接入该清单 |

## 修复后验证（同一安装版，重启后实测）

### 接口层

```
v2/channels/platforms -> xianyu: status=coming_soon, channel=false
可连接频道（channel=true）: 小红书、抖音、快手、视频号
```

### 界面层

| 观测 | 结果 |
| --- | --- |
| 闲鱼在侧栏 | ✅ **置灰**（对比快手/视频号仍为彩色可点） |
| 点击闲鱼 | ✅ 提示「闲鱼 暂未开放，敬请期待」 |
| 是否调用授权接口 | ✅ **`authCalls: []`，完全不再调用** |
| 是否进入扫码弹窗 | ✅ 否 |

截图：`08-修复后-添加频道.png`（置灰）、`09-点击闲鱼.png`（提示）

## 附带查实：12 个声明支持授权的平台，实际只有 4 个可用

| 可用 ✅ | 不可用 ❌ |
| --- | --- |
| 小红书、抖音、视频号、快手 | 闲鱼（缺浏览器 1169）、TikTok / YouTube（引擎签名不匹配 `unexpected keyword argument`）、哔哩哔哩（`不支持的登录平台`）、支付宝生活号 / 百家号 / 虎扑 / 微博（`未获取到平台二维码`） |

后 8 个均 `channel=false`，用户点不到；只有闲鱼漏出，已修复。

## 遗留（建议后续处理）

1. 若要真正支持闲鱼：打包时补 `chromium_headless_shell-1169`（约 +250MB），或让闲鱼改走 playwright 1208；完成后从 `ENGINE_PRESENT_BUT_NOT_READY` 移除。
2. `capabilities.auth.supported` 对 `coming_soon` 平台仍报 true（前端已用 status 判定，不影响用户）。
