## 2 两级结构

| 层级 | 路径 | 角色 |
| --- | --- | --- |
| 基座 | `packages/`、`apps/`、`vendor/`、`native/`、`python/`、`scripts/`、`examples/`、`website/`、`docs/` | DSH 官方基座：不在产品开发范围内，升级内核时整体替换 |
| 产品 | `products/bosom-friend/` | 产品层：内核插件、服务端、桌面壳与打包、前端源码、随包引擎、门禁 |
| 其它 | `analysis/`、`coverage/`、`snapshots/`、`_archive-20260926/`、`courseware/`、`ppt-course/` | 临时工作区与历史归档，不属于交付物 |

**远端仓库**（2026-09-16 起，仍有效）：

| 仓库 | 定位 |
| --- | --- |
| `github.com/Bill-H9986/bosom-friend` | 本仓库的公开镜像：每次整理后把当前整包作为一个无历史快照提交 |
| `github.com/Bill-H9986/zhiyin` | 公开下载与发布仓：只放安装包 Release，不放源码 |

## 3 产品层目录（按六层归位）

| 目录 | 六层归属 | 放什么 | 证据 |
| --- | --- | --- | --- |
| `kernel/` | ② 能力层 | `@deepseek-ai/dsh-bosom-friend-kernel`：31 个 `bosom_*` 工具注册（`src/index.ts` 1839 行） | `kernel/src/{index,drafts,jobs,runner,data}.ts` |
| `server/` | ② 能力层 + ⑥ 记忆层 | 服务端路由、SSE 对话、产品数据店、记忆与蒸馏 | `server/src/api.ts`、`store.ts`、`memory-store.ts`、`knowledge-distill.ts` |
| `bundle/` | ① 运行时层 | 组合补丁层：app / desktop / kernel 三层 | `bundle/app/cordis.patch.yml`、`bundle/desktop/cordis.patch.yml`、`bundle/kernel/cordis.yml` |
| `launcher/` | ① 运行时层 | 启动器与组合配置（开发态 / 随包态同一套入口） | `launcher/config/kernel.cordis.yml`、`launcher/config/desktop.cordis.yml`、`bundle/kernel/runtime/bin-*.mjs` |
| `engine/` | ① 运行时层 | 随包 Python 平台引擎（抖音 / 小红书 / 视频号）+ 胶水层 | `engine/social-auto-upload/` |
| `project/` | ⑤ 呈现层 | 前端源码与 Electron 构建宿主 | `project/bosom-friend-web/`、`project/bosom-friend-electron/` |
| `shim/` | ⑤ 呈现层 | `@deepseek-ai/dsh-web-frontend` 占位包（顶替已退役的 `apps/web`；workspace 只收 `apps/cli`） | `shim/package.json` |
| `desktop/` | ① 运行时层 | 桌面壳（`electron/`）、安装器脚本、打包脚本与产物（`dist/`、`release/` 已忽略） | `desktop/electron/`、`desktop/build-win.sh` |
| `installer/` | ① 运行时层 | C# 安装器源码与图标（编译产物忽略） | `installer/Installer.cs` |
| `qa/` | 贯穿 | 门禁、证据、缺陷台账、文档结构门禁 | `qa/run-gate.mjs`、`qa/verify-docs-index.mjs`、`qa/verify-docs-standard.mjs`、`qa/defects/缺陷台账.md` |
| `docs/` | 贯穿 | 产品文档（规范 / ADR / 知识库 / 过程档案 / releases / reviews / trace / 协作 / 参考资料） | `docs/README.md`（文档总目） |
| `shared/` | ② 能力层 | 共用工具（原子写、进程登记） | `shared/atomic-json.cjs`、`shared/process-registry.cjs` |
| `scripts/` | 贯穿 | 产品打包脚本 | `scripts/打包纯净版.ps1` |
| `tools/` | ① 运行时层 | 媒体工具链（Agnes 媒体） | `tools/agnes-media/` |
| `legacy-archive/` | 历史 | 早期 harness 与旧补丁层 | `legacy-archive/README.md` |
| `analysis/` | 历史 | 临时分析工作区（大体积素材已忽略） | `analysis/` |

**规划中、尚未建立的目录**（见管家化重构总纲-v2.0.md 第 6.1 节，此处不预登记）：

## 4 数据落在哪

| 路径 | 内容 | 谁在用 |
| --- | --- | --- |
| `%USERPROFILE%\.bosom-friend\bosom-friend` | 产品数据根：账号 / 素材 / 草稿 / 任务 / 指标 / 知识库 | 产品运行时（**用户数据，不得删改**） |
| `%USERPROFILE%\.bosom-friend\sessions\` | 内核会话日志（`turn-*`） | 内核运行时 |
| `%APPDATA%\Bosom Friend\kernel-runtime` | 安装版解出来的内核运行时 | 安装版启动 |
| `%LOCALAPPDATA%\Programs\Bosom Friend\resources` | 安装后的随包资源（`runtime/`、`engine/`、`frontend-dist/`） | 安装版启动 |
| `C:\Users\Jay\BosomFriend-Releases` | 回退包库（当前出货版本 + 上一版本，含 SHA256） | 发布与回滚（`qa/baseline/installer-checksums.json`） |
| `%USERPROFILE%\.dsh\` | 开发机 DSH 基座数据 | 开发工具，与产品数据严格隔离 |
| Obsidian 库 | 开发知识库与活记忆（当前状态 / 未闭环 / 流水） | 人与 AI 的跨会话记忆 |

## 5 常跑命令

| 目的 | 命令 |
| --- | --- |
| 会话启动摘要（当前状态 + 未闭环 + 运行状态） | `node products/bosom-friend/qa/session-start.mjs` |
| 开发态启动（端口 31280） | `powershell -ExecutionPolicy Bypass -File products/bosom-friend/launcher/scripts/dev-web.ps1` |
| 文档索引门禁 | `node products/bosom-friend/qa/verify-docs-index.mjs`（要 `DOCS_INDEX_OK`） |
| 文档结构门禁 | `node products/bosom-friend/qa/verify-docs-standard.mjs`（要 `DOCS_STANDARD_OK`） |
| 全量门禁 | `node products/bosom-friend/qa/qa-all.mjs` |
| 出包（仅出包时执行，开发期禁止为验证改动打包） | `powershell -NoProfile -ExecutionPolicy Bypass -File products/bosom-friend/desktop/rebuild-kernel-and-installer.ps1` |

**版本号只有一个权威来源**：`products/bosom-friend/desktop/package.json` 的 `version`（2026-10-11 实测 0.2.62）。
