> 结论先写：**"太AI"不是音量或音色的问题，是"韵律与场景感"的问题**——同一条音色，
> 念得像播音员还是像一个人在货架前随口跟你说，差别在**停顿、语速变化、句尾语气与呼吸**。
> 产品侧能做的三件事：① 换成支持**真人音色克隆**的开源方案（下表的 IndexTTS-2 / CosyVoice 2 / F5-TTS / GPT-SoVITS）；
> ② 把"演绎风格 + 节拍"真正映射到韵律上（产品已有 `voiceProsody`，见 `server/src/digital-human.ts`）；
> ③ 一条片子里的**停顿密度**要跟着画面走（走动 VLOG 的句子更短、停顿更多）。

## 1. 开源方案对照（2026-09 抓取，来源见文末）

| 方案 | 克隆方式 | 中文自然度（主观） | 典型用途 | 本产品怎么接 |
| --- | --- | --- | --- | --- |
| **IndexTTS-2**（B站开源，1.5B） | 零样本克隆（几秒参考音） | 高，情绪与停顿更像人 | 口播、VLOG 旁白 | 本机起 OpenAI 兼容网关；或经硅基流动等托管 |
| **CosyVoice 2 / 3**（阿里） | 零样本 + 指令控制（"用温柔的语气"） | 高，指令可控 | 带货口播、客服 | 已在产品预设里（硅基流动 / 本机自建） |
| **F5-TTS** | 零样本克隆 | 中高，节奏稳 | 长旁白 | 同上（有 OpenAI 兼容封装） |
| **GPT-SoVITS** | 需 1 分钟数据微调 | 高（音色最像本人） | 固定 IP 的长期音色 | 本机自建（产品预设已列） |
| **Fish-Speech / OpenAudio S1** | 零样本 | 中高，情感标签可控 | 多语言 | 本机或托管 |
| **VoxCPM2** | 无 tokenizer，克隆 | 中高 | 实验/自建 | 产品预设已列（本机自建） |
| **Kokoro-82M** | 无克隆，音色固定 | 中（轻量） | 低配机器兜底 | 本机自建 |

**选型建议（本产品）**：默认走 **CosyVoice 2**（已在预设、中文稳、支持指令控制）；
想要"更像真人/更少AI味"就上 **IndexTTS-2**（零样本克隆 + 停顿自然）；
品牌长期只用一个声音、愿意录 1 分钟素材 → **GPT-SoVITS** 微调，音色最贴。

## 2. 为什么现在的配音"出戏"（按影响排序）

1. **音色是通用播音腔**：Edge 的 `zh-CN-XiaoxiaoNeural` 这类默认音色人人都在用，听感立刻"AI"。
   → 换成**克隆音色**（用户自己录 5~10 秒）是收益最大的一步。
2. **句句同速、句尾上扬**：合成器按标点切句、每句一个语调模板。
   → 产品侧：`voiceProsody` 已经按"演绎风格 + 节拍"给语速/音高/音量（`digital-human.ts`），
   但**没有"停顿"这一维**——下一轮应补 `break`/句间静音时长（走动 VLOG 的节奏就靠它）。
3. **文本本身不是口语**：书面句式（"此外""因此"）念出来必假。写稿体裁要求里已经要求口语化
   （见 `SPOKEN_STYLE_RULES`），VLOG 体裁再加"一句一个动作"。
4. **没有环境声/气口**：真人说话有呼吸、有环境底噪。产品是"只贴配音"，成品干净得像播报。
   → 走动 VLOG 体裁应该在画面侧就带环境音（厂商出片自带），配音只压在人声轨道上。

## 3. 本产品怎么换（今天就能做）

设置 → 配音来源（`server/src/tts-provider.ts` 的预设）：

1. **本机自建**：`baseUrl: http://127.0.0.1:8000/v1`（CosyVoice / IndexTTS / VoxCPM2 / GPT-SoVITS 都有
   OpenAI 兼容封装），`model`/`voice` 按各家的命名填，字段名不同时用 `voiceField` / `extraBody` 覆盖。
2. **托管**：硅基流动的 CosyVoice2 预设已内置（免费额度按账号给）。
3. **克隆音色**：IndexTTS-2 / F5-TTS / GPT-SoVITS 都能用几秒到一分钟素材复刻用户自己的声音，
   生成前把 `voice` 换成克隆出来的音色 id 即可——产品侧不需要改代码。

## 4. 下一步（工程项，按性价比排）

1. **韵律补"停顿"维度**：`voiceProsody` 增加句间静音/换气，按节拍给不同长度（口播 0.15s / VLOG 0.3s）。
2. **音色克隆入口**：形象库里加"上传 10 秒参考音 → 生成克隆音色"（依赖用户自建服务提供的克隆接口）。
3. **环境声策略**：走动 VLOG 的画面自带环境音时，配音音量与画面音床的关系要写进体裁要求与拼接参数。
