# 17 · 配音来源：默认的 Edge 能做什么，换成更自然的声音怎么换
> **已废弃（2026-09-25）：本条描述的产品内配音链路已整体删除。**
> 成片里那一声改由厂商（Agnes）在出片时按**念法（persona）**自己念：音色目录、演绎风格、韵律叠加、
> 试听、音色克隆与「设置 → 配音来源」都不再存在（`server/src/tts.ts`、`server/src/tts-provider.ts` 已删，
> 媒体能力面也不再承载语音合成）。本条**保留作历史依据**——它记录的实测边界与选型比较仍然成立，
> 只是不再有任何入口。当前口径见 `docs/功能清单-三大核心功能.md` 的 A6-02 / A6-14 与 Agent Note
> `2026-09-25-vendor-native-speech`。

> 一句话：默认那条链路**免费、不用 Key、开箱能用**；它同时有明确的边界（8 条普通话音色、只认韵律），
> 所以产品把"配音来源"做成可插拔的一层——想更自然就自己配一家，配了就用、配坏了回落并说明。

## 一、默认来源（Edge 朗读接口）的真实边界

2026-09-21 用 `qa/probes/probe-voice-pace.mjs` 与一次 SSML 复测量出来的：

| 事实 | 值 | 出处 |
| --- | --- | --- |
| 接口给的中文音色 | 14 条（普通话 8、粤语 3、台湾普通话 3） | `getVoices()` 实测 |
| 微软更新、更自然的普通话音色 | **拿不到**：`zh-CN-XiaochenNeural`、`XiaomoNeural`、`YunhaoNeural`、`XiaoxiaoMultilingualNeural` 等全部只有 Azure 有，Edge 接口返回 `NoAudioReceived` | 逐条实测合成 |
| 情绪风格 `<mstts:express-as style="…">` | **被丢掉**（整段无声，不报错） | `rawToStream` 复测 |
| 停顿 `<break time="…"/>` | **被丢掉**（同上） | `rawToStream` 复测 |
| `<prosody rate/pitch/volume>` | 生效 | 三种参数实测都改变输出 |
| 输出码率上限 | 96kbps 可用（此前用 48kbps） | 同一句 7.97 秒：47.8KB → 95.6KB，时长一致 |

**结论**：不换来源的前提下，"不那么像机器"能做的只有三件事，产品都做了——
语速按音色实测标定、四拍（钩子/痛点/卖点/号召）韵律落差、写稿要求短句（`SPOKEN_STYLE_RULES`）。
再往上就得换来源。

## 二、换来源：一个配置文件

配音来源是**可插拔的一层**（`server/src/tts-provider.ts`）。在数据根目录放一个 `voice-user.json`
（与 `llm-user.json` 同一个目录）即可，形状就是 OpenAI 的 `/audio/speech` 协议：

```json
{
  "enabled": true,
  "displayName": "Gemini TTS",
  "baseUrl": "https://generativelanguage.googleapis.com/v1beta/openai",
  "apiKey": "你的 Key",
  "model": "gemini-2.5-flash-preview-tts",
  "voiceField": "voice",
  "extraBody": {}
}
```

| 字段 | 作用 | 缺省 |
| --- | --- | --- |
| `enabled` | 关掉就回到 Edge（不填视为关） | 关 |
| `baseUrl` | 到 `/v1`（或各家等价层）为止，程序自己拼 `/audio/speech` | 必填 |
| `model` | 服务商的模型名 | 必填 |
| `apiKey` | 没有 Key 的自建服务留空即可（那时不发 `Authorization`） | 空 |
| `displayName` | 日志与任务记录里的来源名 | 服务地址的 host |
| `voiceField` | 音色参数字段名（个别服务商不用 `voice`） | `voice` |
| `extraBody` | 附加的固定请求字段（各家差异写这里，不写进代码） | 无 |

**配了就会用，用不上一定说**：请求失败时回落 Edge，并在运行日志里留一行
`[TTS_FALLBACK] …；本次回落 Edge 朗读接口`。不静默换成另一种声音冒充同一套配置。

## 三、免费且更自然的选择（按"要不要 Key/实名"排序）

| 选择 | 免费额度 | 要什么 | 自然度提升来自 | 代价 |
| --- | --- | --- | --- | --- |
| **Gemini 2.5 Flash Preview TTS**（AI Studio） | 有免费额度，不用信用卡 | 一个 Google AI Studio Key | 情绪写在提示词里（"像直播带货那样兴奋"），不是三层韵律拼出来的 | 预览模型，免费额度随时可能收紧 |
| **自建开源模型**：CosyVoice 2 / CosyVoice 3.0、VoxCPM2（Apache-2.0）、GPT-SoVITS（MIT） | 完全免费 | 一台能跑推理的机器（0.5B~2B 可 CPU，越大越像人） | 零样本克隆：**用真人录音做音色**，这是一次质变 | 要自己起一个 OpenAI 兼容的语音服务（本配置正好能指向它） |
| **IndexTTS-2**（中文自然度最好的一档） | 完全免费 | 约 8GB 显存的机器 | 细粒度情绪控制（`emo_alpha`）+ 音色/情绪解耦 | **许可证待核**（GitHub 标 NOASSERTION），商用前必须自己确认 |
| 硅基流动 / Fish Audio 等 OpenAI 兼容接口 | 各家政策不同 | 一个 Key（多数要实名） | 直接用到上面那些开源模型 | 实名 + 免费额度有限期 |
| Azure AI Speech F0（500k 字/月） | 有免费额度 | 微软账号 + 信用卡 | 微软自家更新、更自然的音色 + 官方情绪风格 | **商用授权有坑**：微软产品条款把 TTS 产出的商用权利给到付费层，F0 不适合带货出片 |
| Windows 自带 SAPI | 免费无需 Key | 无 | 无 | 实测本机只有 `Microsoft Huihui Desktop`（非神经网络，音质明显更差）；部分 Windows 11 装了"自然语音"包才另有可用项 |

**ElevenLabs 免费档不可用于带货**：免费层没有商用授权、要求署名、不能克隆。

## 四、怎么确认换成功

1. 页面「我的数字人」试听：**试听与成片走同一个来源**（`synthesizeSpeech` 是唯一出口，试听也带 `dataRoot`）；
2. 任务记录与运行日志里的 `provider` 字段：写的是实际出声的那一家，不是"配置里写了哪家"；
3. 运行日志里没有 `[TTS_FALLBACK]`：有它就是自配来源失败、已经回落到 Edge 了。

## 五、还没做的（留给下一轮）

- **界面上的配音来源设置**：目前只能放配置文件（与 `llm-user.json` 同一套"用户自己填"的口径）。
  要放到设置页，需要同时给"测试连接"和"这条音色属于哪个来源"的列表——**切来源必须重选音色**
  （Edge 的 `ShortName` 与别家的音色 id 不通用），这批界面一起来做才有意义。
- **句子级停顿**：Edge 丢掉 `<break>`，所以真正的人味停顿只能靠"逐句合成 + 在句间拼真实静音"。
  这一步会改动母时钟的合成方式，需要连同时长对账一起验（现在各镜时长是按句合成的真实秒数）。
