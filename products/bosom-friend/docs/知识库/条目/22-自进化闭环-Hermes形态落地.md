# 22 · 自进化闭环（Hermes 形态）落地

> 归属：ADR-003 口径四 / C 核心（AI 智能体）
> 日期：2026-09-30
> 结论：**"学"这一半接通了**——对话 → 计数 → 复盘提炼 → 记忆落盘 → 下一轮注入 → 被用上，全链路实跑验证。

## 一、为什么必须做

产品负责人原话："知识库要和 AI 智能体**深度绑定**！这样才能达到 AI 自进化的目的！"

诊断出的现状（可复核）：
- 知识库 `vault.path` 为空、只有 2 条笔记（一条欢迎语、一条被代码明确排除注入的审计日志）；
- `injectedCount = 166`——**注入机制一直在跑，但没东西可注**；
- `distillations = 1142`——**经验原料堆着，从没被提炼**；
- ADR-003 §4 自陈："技能/记忆/画像的蒸馏与 Curator **一行代码都没有**"。

所以"AI 像懵懂大学生"不是模型差，是**它没有被允许记住任何东西**。

## 二、Hermes 的做法（源码级，值得照抄的六条）

1. **容量故意设紧**（MEMORY 2200 / USER 1375 字符）：满了就迫使模型做信息压缩，过时的自然被挤掉；无限追加的记忆文件几个月就膨胀成没人读的怪兽。
2. **超限不静默丢弃、也不自动压缩**：`add` 直接失败并把**现有全部条目**回给模型，让它自己决定替换/合并——这一步本身就是一次自我反思。
3. **冻结快照**：会话启动时取一份，系统提示词用快照（共享 prefix cache）；新写入只改磁盘，下个会话生效。
4. **记事实，不记命令**："用户偏好简短回复"（可被当下覆盖）优于"永远简短回复"（死规矩）。
5. **创建门槛**：工具调用 >5 次才值得建技能；踩过坑再修复的经验才有价值；用户纠正过的必须记。
6. **后台 fork review**：不打扰用户（输出到 `/dev/null`）、限 8 次工具调用、自身 nudge 禁用防递归、与主 agent 共享同一份记忆；审查在回复**发出之后**跑；每个审查 prompt 都以 "If nothing is worth saving, just say 'Nothing to save.' and stop." 收尾，防止硬塞。

## 三、我们的落地（与 Hermes 的两处有意差异）

| 项 | Hermes | 我们 | 为什么 |
| --- | --- | --- | --- |
| 审查执行者 | 后台 fork 一个独立 Agent | **一次模型调用** | 审查要看的材料（对话、步骤、样本）已经在我们手上，fork 一层只会多一份上下文拷贝 |
| 记忆载体 | `~/.hermes/` 下两个文件 | `<DSH_HOME>/memory/{MEMORY,USER}.md` | 同一个口径，落在产品数据根的上一级（内核 `DSH_HOME`） |

模块划分：
- `memory-store.ts`：读写 + 容量纪律 + 人读文件头（`<!-- entries -->` 标记之后才是条目）；
- `self-evolution.ts`：双计数器 + 两套审查提示词 + 解析（容忍模型带编号）+ 阈值收尾；
- `api.ts`：记忆**无条件注入** `streamLlmWithDeltas`（**一处生效 → 8 个调用点同时生效**，这就是"APP 全局辐射"）；复盘挂在助手对话收尾。

## 四、判据（照 ADR-003 原文）

> 同类任务第二次的上下文里出现第一次蒸馏出的技能/记忆条目，且"第 N 次"的耗时或轮数可测地少于"第 1 次"。

本轮实测到的：
- `MEMORY.md` 在第 7 轮被写出一条真实事实（`抖音已连接，小红书未绑定。`），计数归零、`lastReviewAt` 落盘；
- 下一轮问"你记得我什么"，AI 答出**那条记忆**，并在没有记录的地方明说"不想瞎编"。

## 五、三个子系统都跑通后的实测（同日补）

- **记忆**：第 7 轮复盘写出 `抖音已连接，小红书未绑定。`，下一轮被 AI 用上。
- **技能**：一次六维度排查（账号/登录态/数据/草稿/素材/待接待）后**自动生成** `machine-health-audit-0v4be6q.md`，
  六步流程由模型自己写（提示词里没有模板）。门槛 `SKILL_REVIEW_MIN_TOOL_CALLS = 5` 照 Hermes。
- **Nudge 双计数**：`turnsSinceReview`（回合）与 `iterationsSinceReview`（工具调用）分开计，
  实测迭代侧 0→3→5→6→7→8；两条任一过阈值即触发复盘。

## 六、坑（写在这里省下一次重踩）

- **改 server 源码必须"构建 → 刷 `.pnpm` 注入副本 → 重启"三步**，少一步运行时就还是旧代码（DEF-218，当晚最大时间黑洞）。
- **装载期不要调读 `files` 的 `log()`**：那是 TDZ，不是少一条日志，是整个插件树装载失败、服务起不来（DEF-219）。
- 记忆文件用**显式标记**分界，且**说明文字里不能出现标记字面量**（DEF-220）。
