# 20-平台内容标注与合规（2026 最新）

> 来源：中央网信办 2026-05-13 通报《规范短视频内容标注》、抖音星图《内容营销规范》《内容标签审核规范》、
> 小红书《虚假宣传：广告禁用词实施细则》，以及 2026 年三平台审核升级公告。
> 这份条目是**发布前必读**：不按标注规范发布的账号会被依法严惩并公开曝光。

## 一、发布短视频必须选一个「必选标签」（硬要求）

中央网信办把内容标注设为**发布必经环节**——发布者必须从下面 6 类里选一项，才能发布：

| 必选标签 | 说明 |
| --- | --- |
| 含有虚构演绎内容 | 摆拍、剧情演绎、情景还原 |
| **含有 AI 生成内容** | **AI 生成的画面 / 数字人 / AI 配音 / AI 文案成片，一律选这项** |
| 含有营销信息 | 带货、推广、含商业合作 |
| 内容为转载 | 非原创 |
| 内容为个人观点 | 主观评价、经验分享 |
| 无需标注 | 真实生活记录类；**该标签不在视频页面呈现** |

- 首批试点平台：抖音、快手、腾讯、小红书、哔哩哔哩、微博、淘宝、京东、拼多多、支付宝、美团、百度（12 家）。
- 对**存量视频**分批回溯补标；未规范标注的账号会被**依法严惩并公开曝光**。

**对本产品的直接影响**：我们出的是 **AI 生成内容**（AI 画面 / 数字人 / 厂商合成配音），
发布时必须选「含有 AI 生成内容」；若同时带货，还要叠加「含有营销信息」。

## 二、违禁词的审核范围（2026 已扩大）

2026 年三大主流平台审核升级后，**AI 会同时抓取**：

- 字幕（我们烧进画面的字幕）
- 口播（我们让厂商合成的念白）
- 文案（标题、正文、话题标签）
- **背景图**（画面里出现的招牌、证书、屏幕文字）
- **评论区**

任意一处命中违禁词 → **限流 / 降权 / 断播**，多次违规加重处置。

产品里已经生效的写稿禁令（`server/src/speech.ts` 的 `SPOKEN_STYLE_RULES`）覆盖：
极限词、刺激消费词、诱导点击、医疗承诺、联系方式、谐音与变体绕过（绿泡泡 / VX / 某书…）、
第三方平台与店铺名。

## 三、发布前的自查清单

1. **标注**：勾选「含有 AI 生成内容」（带货再勾「含有营销信息」）。
2. **字幕与口播**：不出现极限词、价格承诺、联系方式、诱导话术。
3. **画面**：不出现可读的招牌 / 证书 / 屏幕文字（产品的 `NO_RENDERED_TEXT` 已在逐镜禁用）。
4. **话题标签**：贴合内容、不用违规词做流量词。
5. **账号**：同一账号不要高频发同质内容（平台判重复搬运）。

## 四、产品侧待补
