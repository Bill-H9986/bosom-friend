1. 读 `products/bosom-friend/docs/过程档案/方案与路线/kernel-upgrade-plan.md` 的「执行记录」（补记 1~11，含 9 种失败尝试与根因行号）；

## 常跑的命令

```powershell
# 产品门禁（全量）
node products/bosom-friend/qa/qa-all.mjs
# 门禁单跑（红黄绿语义与清单见 qa/README.md、qa/RELEASE_GATE.md）
node products/bosom-friend/qa/run-gate.mjs
# 出包（内核构建 → lib 同步到所有物理副本 → 依赖核对 → 引擎 → 重打 zip → 解压真握手 → electron-builder）
powershell -NoProfile -ExecutionPolicy Bypass -File products/bosom-friend/desktop/rebuild-kernel-and-installer.ps1
# 开发态 Web（铁律 #12：开发期一律 Web 迭代，别为每次改动打包）
bash products/bosom-friend/desktop/build-win.sh   # 仅在出包时
```
