### 9.1 ② 走动 VLOG 跨镜一致性对账（新探针，已进门禁）

做法：同一个形象（`dh-d4b8bc40`，固定种子 229044）跑两条——A 条两镜都用固定种子、B 条两镜各换随机种子；
同一张形象图、同一组台词与配音、同一组场景提示词，**唯一差别就是种子**；取每镜成片首帧量相似度。

**判据按实测改过一次**：

- 首轮按交接里写的"像素相似度 A 显著高于 B"判红（A 中心区相关 0.472 < 阈值 0.85）。抽帧目视 + 两组三组数
  证明这条判据不成立：第二轮 A（同一个人）只有 0.245，**低于** B 的 0.447；而"同场景不同种子"的 A2↔B2
  能到 0.673。相关系数跟的是**姿态与背景**，不是身份。
- 改后的判据：**由产品配置里的那个模型判"是不是同一个人"**（问句与答案集写死：同一个人 / 不是同一个人 / 看不清），
  判官先过两道自检——真值对（形象图 vs 成片首帧 = 同一个人）与毒丸对（成片首帧 vs 另生成的陌生人 = 不是同一个人）。
  自检不过 → SKIP，不下结论。

**结论**：A1↔A2 = 同一个人（跨镜一致性成立）；B1↔B2 也 = 同一个人 → **身份由参考图锚定，种子只改构图与细节**

### 12.1 症状：五次尝试、四次非绿，红的用例每次都不一样

### 12.2 复现：隔离实例 + 单跑同一条用例

门禁的 E2E 打的是**用户真实数据根**（31280 共享实例），失败会往用户数据里写靶子、也不该反复跑。
按 `qa/probes/run-isolated-long-video.mjs --no-run --keep` 起了隔离实例（31520，配置照抄、数据全新），
单跑 `--grep '级联'`，一次就复现，并拿到失败现场（截图 + `error-context.md`）：

```
TimeoutError: locator.click: Timeout 20000ms exceeded.
  - waiting for locator('button:has-text("批量管理"):visible').first()
  - <div data-state="open" aria-hidden="true" class="fixed inset-0 z-50 bg-black/50 backdrop-blur-sm ..."></div>
    intercepts pointer events
```

页面快照里那个 `data-state="open"` 的遮罩是**平台免责声明**弹层，而它的「同意并进入平台」按钮当时是 `[disabled]`。

### 12.3 根因：夹具只点按钮、不勾选框（DEF-176）

`qa/e2e/fixtures.ts` 的 `dismissDisclaimer()` 里，点击的是「同意并进入平台」，
而这个按钮要**先勾选**「我已阅读并同意以上免责声明」才可点（`disabled={!checked}`）：
点击在禁用态上必然超时、异常又被 `catch` 吞掉，弹层继续开着，它的 backdrop 盖住整页——
**后面每一次点击都被拦**。用例于是红在自己的第一个交互上，报错文本里出现的是"批量管理点不动"
"生成记录弹层点不动"，看起来像删除功能坏了。

**为什么红的用例每次都不一样**：Playwright 每条用例都是全新浏览器上下文（`localStorage` 为空），
免责弹层**每条用例都会重新出现**；哪条先撞上、撞在哪一步随渲染与冷启动快慢而定。
这条同族缺陷也解释了更早的 `gate-20260922-*` 与 `gate-20260923-*` 里"点不动"形态的红灯。
