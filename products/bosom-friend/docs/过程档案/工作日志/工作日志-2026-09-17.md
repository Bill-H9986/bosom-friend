## 1. 内容创作参数没起作用（DEF-082）

### 1.1 真机复现（E2E 实例，隔离数据根）

| 请求 | 实测产物 | 判定 |
| --- | --- | --- |
| 视频 `agnes-video-2.5-flash`，10 秒，1080p，16:9 | `ai-vid-2a2af0b2.mp4` → 10.14 秒 / **1280x720** | 时长 ✅ 比例 ✅ **分辨率 ❌** |
| 图文 `agnes-image-2.1-flash`，1080p，3:4 | `ai-img-9493a096.png` → 1080x1440 | 当时正确（但发的是像素尺寸，见根因） |

### 1.2 根因

1. **能力表是硬编码的**：`ai/draft-generation/pricing` 给每个视频模型都写死 `resolutions: ['720p','1080p']`，
   而 Agnes 官方对 `agnes-video-2.5-flash` 的规则是 `size` 只能是 `"720P"`。用户选 1080p，厂商只可能出 720P。
2. **图片请求发的不是官方字段**：官方 `size` 是档位（`1K/2K/3K/4K`）、画幅走 `ratio`；我们发 `size: "1080x1920"`，
   官方文档明确"不支持的精确尺寸会被标准化"——参数在厂商侧就已变样。
3. **用户选的模型没参与生成**：一律用设置里的 `imageModel`/`videoModel`，界面上的模型下拉只进记录。

### 1.3 修法（新增 `server/src/agnes.ts`，官方规格单一来源）

| 落点 | 内容 |
| --- | --- |
| `agnes.ts` | 官方基址、模型目录（对话/图片/视频）、图片档位与八种画幅（含官方输出像素表）、视频每个模型的 size 白名单与 `seconds` 4~12、六种画幅、参考素材上限、产品档位→官方档位映射 |
| `parseLlmOverride` / `readStoredLlm` | **只填一个 API Key** 就补齐三个通道的模型与地址（非 Agnes 的自定义厂商不受影响） |
| `ai/draft-generation/pricing` | 视频能力按官方逐模型下发（Flash 只 720p、2.5 支持 1080p）；用户自带厂商的模型沿用产品标准档位 |
| `generateAiImages` | 官方字段：`size` 档位（720p→1K、1080p→2K）+ `ratio` 画幅 + `extra_body.response_format`；落盘前仍按产品画布裁剪；模型被 Key 白名单拒（403）时自动换另一个内置图片模型 |
| `generateAiVideoDirect` | 尊重**用户选的模型**；`size` 按该模型官方白名单取值；`seconds` 按官方字符串区间夹紧 |
| 设置页 | 内置 Agnes 卡（`agnes-builtin`、`builtin=true`）恒在，用户只填 Key；不给"删除"这个假动作 |

### 1.4 验证

- `server/test/functional/agnes.spec.ts` **12 条通过**（档位映射/画幅白名单/每模型 size/seconds 夹紧/素材上限/
  只填 Key 补齐三通道/内置卡落盘与回读）。
- `server/test/functional/content-params.spec.ts` **12 条通过**。
- `server/test/functional/video-reference.spec.ts` 4 条通过（用例里的 `model` 改成真厂商模型名：
  选本地模板只走本地幻灯片，不再调厂商）。

## 2. 内置浏览器不保留登录态（DEF-083）

根因三处：引擎开页走 CDP `/json/new`（默认会话，读不到 `persist:zhiyin-*` 里的登录态）；
外部实例每次启动都新建随机用户数据目录（"每账号隔离"实现成了"每次隔离"）；退出前不落盘。

修法：新增 `electron/main/plat/platformWindows.ts`（九个频道平台各一个持久分区隐藏窗口，
分区表与登录窗口共用同一张表）；`browser-bridge` 的平台站点先进自己的持久窗口；
外部实例按「浏览器类型 + 平台」复用目录；退出前 `flushPlatformCookies()`。
验证：`tsc --noEmit` 与改动前一致（仅剩仓库既有的 harness 缺模块报错）；真机登录实测待出包。

## 3. 长视频：稿件太短与 5 秒静音（DEF-084）

### 3.1 真机数据（装机版数据根，两条 90 秒任务）

| 任务 | 稿件 | 成片 | 有声 | 静音 |
| --- | --- | --- | --- | --- |
| `lv-d3196a2c`（用户看的那条） | **346 字**（下限 405） | 86.2 秒 | 46.2 秒 | **40.0 秒（46%）** |
| `lv-3fd5a5a5`（本轮在跑） | 523 字 | — | — | 8 个静音镜 × 5.00 秒 |

`ffmpeg -af silencedetect=noise=-35dB:d=0.8` 在成片 **25.3–30.6 秒**测到 **5.34 秒**连续静音——
用户说的"5 秒停顿"是可测量的，不是感觉。

### 3.2 根因

1. 长度校准只补写一次、只在"第二次更长"时才采用，仍不够也照跑（静默接受短稿）；
2. 分镜要求"product/scene 镜的 line 留空"+固定 5 秒，而厂商图生视频只出画面没有音轨 →
   每个产品镜就是一段 5 秒静音；同时"全文不少于 405 字"与"每镜 18~27 字 + 40% 镜头没台词"
   在字数上互相矛盾，模型怎么写都对不上。

### 3.3 修法

- **旁白铺满时间轴**：分镜要求每镜都有 line（画面切走、口播不停）；新增 `fillMissingLines` 兜底；
  兜底分镜把口播句按顺序分给所有镜头，句子用完就不再插产品镜。
- **配音贴回画面**：`attachVoiceOver`（`tpad=stop_mode=clone` 补长 + `-shortest` 收在配音上；
  贴音失败保留无声成片并留日志，不让这一镜失败）。
- **短稿不放过**：最多 3 轮补写、每轮带"还差多少字"、每轮取最长的一稿；3 轮仍低于下限就
  **在任何厂商调用之前**如实失败，文案给出"把卖点写细一点，或把目标时长降到约 N 秒"。

### 3.4 验证

- `storyboard.spec.ts` **26/26 通过**；`long-video.spec.ts` **47 条**（含短稿三轮后失败、
  无静音镜、内置 Agnes 按官方档位一次到位 / 自定义厂商"被拒一次后记住"）**全绿**。
- 装机版真机复核待重出包（服务端代码已就绪）。

### 3.5 顺带修掉的一条（DEF-085，本轮真机撞上）

用户那条 90 秒任务在 **11:06 停在第 16 镜**，失败原因是"厂商没有受理这次生成任务"**不带 HTTP 状态**——
按代码路径唯一对应"三次下单一次响应都没拿到"（网络失败/超时）。它被判成**永久失败**，
于是整条已经跑成 15 镜的任务就此判死。修法：这条路径改成 `[可重试]` 前缀，
交给编排层自动重跑这一镜（与 429/5xx 同一档），不再让一次网络抖动吃掉前面所有额度。

## 4. 用户第二轮报障（截图 + 三句话）：内置模型、数字人跳人、音色太少又太假（DEF-087 / DEF-088 / DEF-089）

用户原话：「这个内置模型就改成 agnesAI 的相应模型！但是具体的模型型号还是得在设置里配置！」
「为什么长视频创作时数字人会跳？就是我明明用的一个数字人，为什么会跳到别的数字人去了？」
「音色太少了！而且 AI 味太浓一点都不自然！」

### 4.1 内置模型其实是本地幻灯片模板（DEF-087）

截图里的「Bosom Friend视频脚本模板 · 720p · 5-60s」是 `zy-template-video`：选它时服务端
**不调厂商**，成片是把图片串起来的静止画面轮播，而且它宣称的 5~60 秒与厂商的 4~12 秒硬冲突。
修法：内容创作的模型清单只摆厂商模型（第一条 = 设置里配置的那个型号），幻灯片退回成
"厂商调用失败时的降级"并如实标注（既有行为不变）。

### 4.2 数字人跳人：两条独立原因，都有真机证据（DEF-088）

真机数据根里翻出来两件事：

| 证据 | 说明 |
| --- | --- |
| 三条 90 秒任务的 `productImageUrl` 都是 `asset-accept.png` | 而它与 `asset-dh-closed-loop.png` 字节数完全相同，**正是另一位数字人「验收数字人」的形象照** |
| 同一批任务的镜头 `visual` 原文 | 「近景，**演员**侧脸对着镜头…」「中景，**演员**双手合十靠近胸口…」「主播抬手轻抚脸颊…」「一只手自然托起产品…」 |

于是两处各自把第二张脸送进了生成链路：口播镜把产品图当第二张人脸参考交给厂商（`reference` 模式两张图 → 融合）；
非口播镜的参考图里只有产品，厂商按文字画人只能自己编。更硬的一处：产品镜只有一张参考图时厂商走
`keyframe` + `first_frame`，**成片第一帧就是那张图**——人像当产品图，那一镜从第一帧起就是另一个人。

修法：口播镜只交形象图一张（"是谁"由形象图定、"怎么复现"由种子定）；非口播镜在提示词与下单处
两处强制"不出现人脸/第二个人"；产品图位与形象库中任一形象图相同的当场拒绝并说明；形象缺 `seed`
（老数据）时补一个并落盘。

### 4.3 音色太少、念法太机械（DEF-089）

- 音色：接口实测给 **14 条**中文音色（`getVoices()` 返回 322 条语音），产品只摆了 8 条——
  粤语 3 条与台湾普通话 3 条从来没被摆出来。现按接口清单补齐，每条带口音分组、声音特点与适用内容。
- 语速：同一句样音在 14 条音色上实测 7.03~10.75 秒（**2.98~4.55 字/秒，差 53%**）。
  原先按全局 4.5 字/秒折算：选慢音色的用户成片被拖长三分之一，选快音色（云扬/云哲）念带货像播新闻。
  现每条音色带实测语速 + 基准韵律补偿（±15% 上限），语速参与写稿字数与镜头时长折算。
- 念法：新增 5 条**演绎风格**（自然亲切 / 温柔慢语 / 利落干练 / 元气带货 / 沉稳专业），
  试听与成片用同一套韵律；音色 × 风格 = 70 种组合。三层韵律（音色基准 + 风格 + 节拍）逐轴求和后夹紧
  （语速 ±15%、音高 ±6%、音量 ±15%），最坏组合也不会叠出假声。
- 四拍落差加大（钩子 +12% / 痛点 -8%……），并新增写稿"人话"判据（短句、口语词、禁书面语与行业黑话）。
- 负面结论（省得后来者再试）：SSML 的 `<break>` 与 `mstts:express-as` 实测都不被 Edge 朗读接口支持
  （请求以"流提前关闭"失败），停顿只能靠句子写短。探针与实测表：`qa/probes/probe-voice-pace.mjs`、
  `qa/probes/voice-pace-2026-09-17.md`。

- `digital-human.spec.ts`（新增 11 条）、`storyboard.spec.ts`（28 条）全绿；
- `long-video.spec.ts` 新增/改写：口播镜恒 1 张参考图、非口播镜带人物禁令、产品图=形象图被拒、

## 5. 用户第三轮要求：整个 APP 只内置 Agnes 服务商，但**不要内置任何大模型**（DEF-090）

用户原话：「整个 APP 只内置 Agnes AI 服务商！但是不要内置任何大模型！能明白吗！
所有内容创作中在设置里配置大模型就有选项！没有配置大模型就给提示！！！！」

设置页自己一直写着"系统不内置任何大模型"，而代码在三处内置了模型——这次把这句话变成事实。

### 5.1 三处"替用户挑了模型"

| 位置 | 表现 |
| --- | --- |
| `agnes.ts` 的 `AGNES_MODELS` | 8 个型号的写死目录（4 对话 + 2 图片 + 2 视频），设置页内置卡直接摆出来当"他能用的清单" |
| `parseLlmOverride` / `PUT ai/user-llm` | 只填一个 Key 就自动补 `model`/`imageModel`/`videoModel` 三个官方默认型号 |
| `ai/draft-generation/pricing` | 内容创作的清单 = 配置的那个 + **全部内置型号**（还多一条本地排版模板 `zy-template-image`）；`generateAiVideoDirect` 被 401/403 拒时静默换用下一个内置型号 |

### 5.2 修法

1. `agnes.ts` **只留参数契约**（档位/画幅/时长/素材上限）：它回答"用户配了某个 Agnes 型号时请求怎么发"，
   不再回答"产品提供哪些型号"；目录、默认型号、内置卡配置生成器一并删除；
2. 内容创作的模型清单 = **用户配置的那一个**（图片、视频各一个）；没配就是空清单，
   前端在下拉里给出「去设置里配置模型」（点开即跳设置的自定义大模型页）；
3. 设置页内置卡：接口地址仍由内置规格补齐（服务商是内置的），**模型目录从空开始**；
4. 生成时只试用户配的那个型号；被拒（401/403）如实回原因，不再"换一个内置型号再试"；
5. "没配完"的判据统一成**地址 + 密钥 + 型号**三样齐全：对话（引导回复）、写稿/分镜
   （`missingChatModelReason`）、内容创作（下拉空状态）三处给的是同一件事——去哪、做什么。

### 5.3 验证

- `agnes.spec.ts` 16 条通过（不补型号 / 填了就原样用 / 清单 = 配置的 / 没配为空 / 未配给提示）；
- `content-params.spec.ts` 的夹具先配型号再断言档位（否则空清单会让断言空转）；
- `npx tsc --noEmit`（server）干净；前端 `tsc --noEmit` 无新增错误、`vite build` exit 0；
- **隔离实例浏览器实测**（31399 + 临时数据根，未动用户数据）：
  配了型号 → 模型下拉只有 `agnes-image-2.5-flash（已配置）` 一条（连"内置"那一条也没了）；
  清掉配置 → 胶囊显示"未配置模型"，下拉给出说明与「去设置里配置模型」，点它直接打开设置的「自定义大模型」页；
  `GET ai/user-llm` 的内置卡模型目录为空、`GET ai/models/chat` 只列用户配的三个型号；
- 证据：`qa/evidence/model-voice-fix-2026-09-17/`（01 未配置 / 02 点提示打开设置 / 03 配了模型只有一条
  / 04 我的数字人 14 条音色与 5 种演绎风格）。

## 6. 用户第四轮报障（四条体验问题）：记录不能删、数字人排版挤、任务要手动刷新、素材组删不掉（DEF-091 ~ DEF-094）

用户原话：「长视频创作的记录没有删除选项！」「我的数字人板块排版太拥挤了，优化一下！」
「我的任务在每次新开对话时都要手动刷新才能展示最新的对话！」「为什么内容创作又多了两个素材组？
要么就只一个素材组！要么就提供添加删除功能并各素材组数据独立！」

### 6.1 素材组为什么多了两条（先查数据，再改代码）

真机 `material-groups.json` 里确实有三条：用户的「默认素材组」（4 条草稿）+ 两条空的
「AC-007-2目标组1789400482385」「AC-007-2源组1789400482385」——**是验收 E2E 建的**：
`qa/e2e/specs/ac-verification.spec.ts` 的自建自删写在用例末尾，断言一失败就留在了真实数据根里
（E2E 按设计打的就是正在运行的实例，这违反了 `qa/e2e/README.md` 规矩 #1"失败也会在 finally 里清理"）。

**删不掉的另一半原因**：`PlanTabBar` 只在素材组多于一个时渲染，而且渲染时只画标签——
「更多（重命名/删除）」与「新建」两个入口连同组件一起丢掉了（`MorePanel` 成了没人引用的死代码）。
管理入口寄居在展示组件上，一隐藏就全没了。

修法：横条恢复两个入口并有组就显示；默认素材组不可删（界面置灰 + 服务端拒绝，它是首屏落点）；
组里有内容时拒绝删组并报出条数；E2E 清理进 `finally`；机器上两条残留空组已清掉（先备份
`material-groups.json.before-cleanup-<时间戳>.bak`，走产品自己的删除接口）。

### 6.2 长视频记录可删

新增 `DELETE long-videos/:taskId`：**删记录不删成片**（成片已经作为草稿进了内容库，
删了那条草稿就变成打不开的视频），只清工作目录与逐镜成片；生成中拒绝删除（后台还在逐镜写回）。
列表每条加「删除」+ 二次确认，并补了「展开全部 N 条」——原来只看最近 6 条，
用户积了 14 条，剩下 8 条既看不见也删不掉。

### 6.3 我的任务即时刷新

新增 `@web/utils/agentTaskEvents` 广播：Agent store 在「任务 id 就绪 / 生成完成 / 停止生成」三个时刻
通知一次，任务列表订阅后**立刻**按当前筛选条件重拉（原来的聚焦/可见/30 秒轮询保留作兜底）。

### 6.4 我的数字人重排

容器放宽、四段各用分隔线分段、音色说明放进浅底色块、5 个念法卡片改 2~3 列网格、卡片列表同步放宽。

### 6.5 验证

| --- | --- | --- |

| 远程带令牌 · 接口 | code 0，读到任务列表 |
| 远程错误令牌 | 40100 |

| 隧道（本机没装 cloudflared） | 如实报"本机没找到 cloudflared…或填自己的隧道命令"，不假装成功 |

### 8.1 上传入口改成原生 `<label>`（DEF-097）

- 旧写法：`<Button onClick={() => inputRef.current?.click()}>` + `className="hidden"` 的 input。
  这条路要"引用没丢、元素在文档里、浏览器接受一次非用户手势的点击"三件事同时成立，

  禁用态用 `aria-disabled` + `title` 说明原因（label 不支持 `disabled`）。

  坏的只有入口。

### 8.2 自己撞出来的数据事故：BOM 三个字节让整个内容域 400（DEF-098）
