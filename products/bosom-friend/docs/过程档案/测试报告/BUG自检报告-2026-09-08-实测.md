## P0（阻断发布）

### BUG-01｜后端直连模型接口（架构红线）
- **位置**：`products/bosom-friend/server/src/api.ts:228`
- **证据**（源码）：
  ```ts
  const res = await fetch(override.baseUrl.replace(/\/$/, '') + '/chat/completions', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Authorization: 'Bearer ' + override.apiKey },
    body: JSON.stringify({ model: override.model, stream: true, messages: [...], max_tokens: 4000 }),
    signal: AbortSignal.timeout(deadlineMs),
  })
  ```
- **问题**：手写 OpenAI 兼容 `/chat/completions` 流式调用，**绕过官方 DSH 内核**，违反"DSH 是唯一运行时"铁律（铁律 #2）。存在第二套会话状态风险。
- **修复方向**：迁到 `server/src/kernel-client.ts` 的 `createKernelClient().prompt()`，经官方 SDK 走内核。

### BUG-02｜禁止依赖 DSH Web UI 包（×3）
- **位置**：`products/bosom-friend/launcher/package.json`、`bundle/app/package.json`、`legacy-archive/bundle-app/package.json`
- **证据**：三处 manifest 均声明 `"@deepseek-ai/dsh-web-app": "workspace:^"`
- **问题**：依赖 DSH Web UI 包，违反"自研前端显示层、不用 DSH 网页 UI"边界（`legacy-archive` 为已归档可豁免，但 `launcher` 与 `bundle/app` 必须移除）。

## P1（影响交付/质量）

### BUG-04｜AC 状态失真（追踪失实）
- **证据**：RTM 中 `AC-021-1/2/4`（纯正 .exe、干净机器安装/升级/卸载）标"**未实现**"，但 M6 里程碑已产出 `BosomFriend-Setup-0.2.0.exe` 并完成"干净室"验收（提交记录在案）。
- **问题**：**AC 状态没有跟现实同步**，追踪体系失真——门禁据此误报红灯。需人工核验后更新状态/补证据。

### BUG-05｜AC 总数与覆盖率计算不一致
- **证据**：`run-gate.mjs` 报覆盖率计算分母=45；RTM 实际仅 41 条 AC（AC-001-1 … AC-021-4）。
- **问题**：门禁与 RTM 的 AC 总数对不上，覆盖率为 3.3%（部分 3×0.5/45）可能算错。需对齐两侧来源（前端功能需求盘点清单 20 REQ / 41 AC）。

### BUG-06｜`vendor/cordis/tsconfig.json` 被误删，破坏类型检查/构建
- **证据**：`git status` 显示 `D vendor/cordis/tsconfig.json`；`tsc` 报 `TS6053: File 'vendor/cordis' not found`（波及 `server`、`packages/host/webserver`、`packages/llm`、`packages/runtime-diagnostics/invariants`、`packages/attachment`）。
- **处理**：已用 `git checkout -- vendor/cordis/tsconfig.json` 恢复。根因疑为早前 git 手术事故/误删残留。
- **影响**：不恢复则整包类型检查与构建全断。

## P2（质量/配置）

### BUG-07｜server tsconfig 与 workspace 引用配置冲突
- **证据**：`npx tsc --noEmit -p products/bosom-friend/server/tsconfig.json` 报 `TS6059`（`packages/code-runtime/src/types.ts` 等不在 server `rootDir`）与 `TS6307`（文件未列入 project file list）。
- **问题**：server 项目的 project-references/rootDir 配置不一致（把 `packages/*` 源码经路径拉进 program，又与 server `rootDir` 冲突）。需按仓库"src 面 / 构建面"约定（`docs/development.md`）用聚合 face 或正确 `references` 跑。

### BUG-08｜门禁脚本路径过时（误报红灯）
- **位置**：`products/bosom-friend/qa/run-gate.mjs`
- **证据**：检查 `launcher/src/bin.ts`（不存在），而实际入口是 `bin-kernel.ts` / `bin-desktop.ts`（后者已绿）。
- **问题**：门禁脚本检查了过时路径，导致"DSH 内核组合"误报红灯（非产品缺陷，但影响门禁可信度）。
