## 六、Bosom Friend新后端 @deepseek-ai/dsh-bosom-friend-server

**组合方式**：`products/opc/bundle/opc-app/cordis.patch.yml` 插入 `bosom-friend-server-api` 行 → 插件随 OPC 启动器加载，路由挂 dsh webServer。

**源码文件（`products/bosom-friend/server/src/`）**：

| 文件 | 职责 |
| --- | --- |
| `api.ts` | 插件入口 + `apply()`：`/bosom-friend/api` 路由分发、SSE 对话（`init→stream_event→result→done`）、LLM 桥（20s 硬截止+模板兜底）、`/bosom-friend` 静态托管 + index.html 注入（backend url / auth token / IPC shim） |
| `routes-channels.ts` | 渠道域：平台元数据、授权会话、账号 CRUD/分组、发布流/记录/任务、作品分析、归属校验 |
| `routes-content.ts` | 内容域：素材组/素材、媒体库、OSS 三步上传、数据中心看板、话题搜索、笔记互动搜索、热榜、抖音小程序、反馈 |
| `store.ts` | 持久层（JsonFile 原子写 + 默认值 + 默认分组保证） |
| `types.ts` | 域类型（字段对齐前端 TS 接口） |
| `http.ts` | 信封 `{code,data,message}`、CORS、body 读取、SPA 注入（__BACKEND_BASE_URL__/__ZHIYIN_AUTH_TOKEN__ + ipcRenderer`_events` shim） |
| `store-helper.ts` / `invariant.ts` / `index.ts` | 工具/包级 invariant/模块说明 |

**端点规模**：注册路由 **107+ 条**（契约审计：前端 44 个字面 URL 全命中；模板串 URL 逐条核对）。域：认证(7)/Agent 任务+SSE(20)/AI 能力与草稿生成(12)/渠道与账号(22)/发布(12)/平台授权(4)/素材与媒体(20)/数据中心(2)/笔记搜索(10)/热榜(6)/小程序与反馈(3)。

**兼容设计要点**：恒 HTTP 200 + 业务码；code===0 成功；三处 `api//` 双斜杠归一化；DELETE 带 JSON body；数组 query `ids=a&ids=b`；SSE 事件结构与前端 sse.handler 完全对齐。
