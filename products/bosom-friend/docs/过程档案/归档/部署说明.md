## 启动 / 停止

- 启动（双击）：`start-dsh.cmd` —— 使用系统 Node.js 启动 Web UI（默认端口 3080，自动打开浏览器）。
- 停止（双击）：`stop-dsh.cmd` —— 结束监听 3080 端口的进程。
- 或手动执行：

```bat
"C:\Program Files\nodejs\node.exe" "%~dp0apps\cli\lib\bin.js" web
```

浏览器访问：`http://127.0.0.1:3080`

## 环境要求

- Node.js `^22.19 || >=24`（本机为 v24.18.0，位于 `C:\Program Files\nodejs`）
- 建议使用 pnpm 11.7.0（仓库锁定的 `packageManager`）

> 注意：本机 PATH 中 `pnpm` 首先解析到 `DSH Desktop\runtime-commands\bin\pnpm.cmd`，
> 它把 pnpm 运行在 Electron/Node 环境里（Node 24.18.1，非系统 Node），
> 会导致 esbuild 等原生依赖的 postinstall 校验失败。因此部署/启动脚本均
> 显式使用系统 Node 运行 pnpm 与 `dsh` CLI（见 `start-dsh.cmd`）。

## 数据安全保证（自研产品 · 自研内核，可核验条款）

1. **本机回环**：服务仅绑定 `127.0.0.1`（实测 netstat），局域网/其他设备一律无法访问；部署机上只有一个产品进程（端口 3081）。
2. **数据不出网**：使用全流程实测（首页/创作/发布/数据/监控/设置/对话）浏览器**零外发请求**（qa/probes/probe-net.mjs）；产品不接任何遥测/统计上报。
3. **密钥最小化**：用户 API 钥匙只存在浏览器 localStorage，随请求发送到本机服务内存处理——不落盘、不上传任何第三方；唯一可能出网的机会 = 用户配置的自家 AI 接口调用（BYOK）。
4. **原子持久化**：全部数据 JSON 原子写入（临时文件+重命名），崩溃不产生半截文件；数据格式可直接阅读（JSON）。
5. **数据全量即目录**：`~/.bosom-friend/` 一个目录 = 全部数据；整体复制即备份、整体删除即完全清除，无其他存储位置。
6. **管理员主机独立**：产品数据根可 `BOSOM_FRIEND_HOME` 指向任意受控目录（如加密盘）。
7. **根因可溯源**：数据写入仅发生在产品进程（3081 服务）；开发助手数据在 `~/.dsh/`，产品不读写（见独立性边界）。
8. **无 Cookie/账户体系**：当前版本单机单用户、无云端账号，不存在云端存用户数据问题；正式版上服务器时再引入账号与加密存储（另行规划）。
9. **ACL 自动收紧（已实现，零操作）**：启动时 icacls 移除继承、仅授当前用户全权（实测：数据目录只剩当前用户一个 ACE）；
10. **自动备份轮转（已实现，零操作）**：启动即全量 JSON 快照至 `<根>/backups/<时间戳>/`，保留最近 30 份，整体复制即导出；
11. **启动自检（已实现，零操作）**：完整性校验全部 JSON 可解析，报告落 `security.json`，并由设置→系统与更新「数据安全」卡如实展示（访问范围/零外发/目录保护/备份/完整性）。

## 独立性与数据安全边界（产品 ≠ 开发 DSH）


- **两个完全独立的系统**：Bosom Friend/OPC 产品与开发机上的 DeepSeek Harness（~/.dsh）互不关联——产品启动时在进程内设置独立数据根（launcher bin.ts），产品域内一切路径解析到 **`~/.bosom-friend/`**（可用 `BOSOM_FRIEND_HOME` 显式覆盖）；
- **产品绝不触碰 `~/.dsh`**：不读写其数据目录、配置、会话、profile、凭证（含 .credentials.yaml）；产品密钥一律来自用户自行配置（设置页 BYOK）或标准环境变量；
- **数据安全**：用户数据全部在 `~/.bosom-friend/bosom-friend/`（JSON 原子写入），密钥仅存浏览器 localStorage 并随请求到本机服务执行，不落盘、不上传任何第三方；UI 中数据位置已如实展示；
- 移除开发 DSH 的 `~/.dsh/bosom-friend`、`~/.dsh/opc` 旧产品目录后，本产品运行不会再生成它们（实测旧根不存在、新根实时写入）。

## AI 模型策略（当前：完全免费 + 无内置模型）

- **卖的是系统，不是 API**：产品当前完全免费；所有 AI 均使用**用户自己的钥匙**（设置 → AI 模型服务，Agnes 国内站免费注册领取，BYOK），按用户自身账户计费；
- **系统不内置任何大模型**：后端 `bosom-friend-server` 不含任何模型调用（无 provider/model 配置、无额度/卡密/扣点）；未配置钥匙时 AI 回复为内置模板 + 指引（文案明确“请配置你自己的钥匙”）；
- 用户钥只需保存在浏览器 localStorage，随每次请求发送到本机服务执行，不落盘、不上传第三方；
- **后续服务器正式版收费**：届时在服务端引入账号体系与套餐计费（本机版不受影响），模型策略不变（仍可 BYOK）。
