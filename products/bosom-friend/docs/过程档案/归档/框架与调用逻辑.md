## 三、启动与组合（调用链 ①）

```
start-opc.cmd —— 自适应端口 3080~3085（被 dsh web 占用则顺延）──▶ node products\opc\launcher\lib\types\bin.js --port <N> --no-open
  └─ products/opc/launcher/src/bin.ts：boot('opc', products/opc/launcher/config/cordis.yml(空根配置), patches, provideCmdline)
       └─ 按序叠加 BUNDLES…：@deepseek-ai/dsh-base → @deepseek-ai/dsh-web-app → @deepseek-ai/dsh-opc-app
            └─ dsh-opc-app/cordis.patch.yml 插入：
                 bosom-friend-server-api（dataRoot=~/.dsh/bosom-friend）
                 opc-publish / opc-analytics / opc-drafts / opc-api / opc-support（dataRoot=~/.dsh/opc）
                 system-prompt（覆盖 Web 基座 persona →「OPC 全能助手」）
  └─ webServer 路由：/bosom-friend/*（SPA+API） · /opc-platform/ · /（官方 Web UI）
```

- 产品启动器**不依赖** `~/.dsh/profiles`（产品隔离）；裸插件名解析锚定安装根（`products/opc/launcher/config/node_modules` 回退目录）。
- 一键停止：`stop-opc.cmd`（按端口找进程）。

## 四、Bosom Friend 页面加载链（调用链 ②）

```
GET /bosom-friend/ ──▶ bosom-friend-server api.ts serveSpa：
  1. 从 bosom-friend-electron/dist 读 index.html（vite build --mode=test 产物，相对路径资源）
  2. 注入 __BACKEND_BASE_URL__='/bosom-friend/api'（前端 axios baseURL）
  3. 注入 __ZHIYIN_AUTH_TOKEN__（免登录会话 token）
  4. 注入 window.ipcRenderer shim（on/off/_events/setStoreValue 等，浏览器环境替代 Electron preload）
  5. 返回 HTML → 前端 bundle 启动 → WebAppLayout 渲染
```

前端结构（project/bosom-friend-electron + bosom-friend-web）：

```
src/App.tsx（渲染器入口）
 └─ desktop-pages/WebAppLayout          ← 桌面壳布局（唯一界面来源）
     ├─ LayoutSidebar（导航 7 项 + LogoSection + 底部功能区 + 用户区）
     ├─ MainContent（页面路由：'#/' 首页 Hero、draft-box、tasks-history、ai-interaction、
     │              knowledge、calendar、data-statistics、monitor、settings、accounts）
     ├─ AIAssistantPanel（右侧 AI 助手：紧凑头部 + 收起重叠替换 + SSE 对话）
     ├─ DisclaimerModal / AgentTestingNoticeDialog（首启免责 + Agent 测试期提示）
 └─ store/（zustand）：user / agent（任务+SSE 会话）/ aiAssistant（面板收起）/ system / llmConfig / settingsModal
 └─ api/（axios 层）：先封装 {code,data,message} 信封 → 各域 api（channels/content/…）
 └─ i18n/locales/* ×7（zh-CN/zh/en/de/fr/ja/ko），directTrans/useTransClient
```

- 路由切换用 hash（`#/xxx`）；monitor/calendar/data-statistics 为复用组件独立页（发布日历、数据中心本身无页眉标题——全站功能页已统一无标题）。
- Electron 桌面壳（host 的 electron/main + preload）仍指旧后端 8080（已知限制，见清单第九节）。

## 五、业务 API 调用链（调用链 ③，普通域）

```
页面组件 ─▶ 域 api 函数（src/api/*）──▶ axios(interceptor) ──▶ POST/GET /bosom-friend/api/<路径>
  └─ interceptor：baseURL=window.__BACKEND_BASE_URL__；信封解包；code!==0 抛业务错；
     兼容旧约定：'api//xx' 双斜杠归一化、DELETE 携带 JSON body、GET 数组参数 ids=a&ids=b
  └─ bosom-friend-server api.ts：URL 匹配分发（注册 107+ 路由，13 个业务域）
       ├─ routes-channels.ts：认证(7) / Agent 任务(SSE+CRUD 20) / AI 能力与草稿生成(12)
       │     / 渠道与账号(22) / 发布(12) / 平台授权(4) / 接待域(rules×4+test+handle+logs×3 等 8) / 分析
       ├─ routes-content.ts：素材与媒体(20) / 数据中心(2) / 笔记搜索(10) / 热榜(6) / 小程序与反馈(3)
       └─ 路由执行器：业务逻辑 → store.ts 读写 → 返回 {code:0,data,message}（恒 HTTP 200）
  └─ store.ts：~/.dsh/bosom-friend/*.json（JsonFile 原子写：临时文件+rename；默认值 + 默认分组保证；user/accounts/groups/materials/tasks/metrics/records/notifications/logs…）
```

**信封约定**：`{code, data, message}`；`code===0` 成功；HTTP 200 承载业务错误（前端按 code 分支）。

## 六、AI 对话 SSE 链（调用链 ④）

```
右侧 AI 面板 / 任务记录 / 首页输入 ─▶ store/agent.createTask/continueTask
  └─ POST /bosom-friend/api/agent/tasks（SSE, fetch-event-source）
       └─ api.ts：任务持久化(status=running) → 用户钥匙 LLM 桥（BYOK OpenAI 兼容流式；无钥匙→模板兜底+引导，系统不内置模型）
            ├─ 成功：流式返回 init → stream_event×N（delta/代理块） → result → done
            └─ 兜底：无 Key / 20s 硬截止 → 本地模板回复（沟通闭环永不悬死）
       └─ 前端 sse.handler：按事件结构增量渲染；完成后任务 status=completed
  ├─ POST agent/tasks/:taskId/abort（停止） · /rating（评分） · /share（分享） · /favorite（收藏）
  ├─ GET  agent/tasks/:taskId/messages · agent/tasks/shared/:token · agent/tasks/cleanup-running
  └─ AI 子域：ai/models/chat · ai/logs · ai/chat · ai/draft-generation/*（草稿生成 v2/图文/Pricing 等）
```

```

  ├─ qa-guard.mjs（功能/品牌/布局/i18n 21 项）→ last-guard1.json
```
