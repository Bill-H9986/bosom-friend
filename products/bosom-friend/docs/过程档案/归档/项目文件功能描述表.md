# 项目文件功能描述表

> 项目：Bosom Friend APP = DeepSeek Harness 基座（v0.1.1-rc.2）+ OPC 平台层 + Bosom Friend 产品层
> 生成日期：2026-08-28 · 配套导航：[项目整理清单.md](项目整理清单.md) / [框架与调用逻辑.md](框架与调用逻辑.md) / [部署说明.md](部署说明.md)

## 一、启动 / 停止 / 打包脚本（根目录）

| 文件 | 功能描述 |
| --- | --- |
| `start-opc.cmd` | 产品一键启动：端口自适应 3080→3085，首启自动生成插件回退链接，启动后打开 `/bosom-friend/` 首页 |
| `stop-opc.cmd` | 按监听端口匹配并结束产品后端进程 |
| `start-dsh.cmd` | 官方 DSH Web UI 一键启动（固定 3080，系统 Node 运行） |
| `stop-dsh.cmd` | 结束监听 3080 的官方 UI 进程 |
| `main.js` | Bosom Friend 桌面版 Electron 主进程 v8：用自带 Electron 以 Node 模式自举后端、自动选端口、加载前端、退出回收子进程 |
| `打包发布.ps1` / `打包发布.bat` | 绿色发布包生成脚本：robocopy 复制代码树 → `release/BosomFriend-v0.13.5` 并生成 `install-deps.bat`、`使用说明.txt` |
| `setup-BosomFriend.exe` | 安装包（发布产物） |
