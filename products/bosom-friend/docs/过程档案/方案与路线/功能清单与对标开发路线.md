# Bosom Friend 功能清单与对标开发路线（AI 全自动工作台 · DSH 唯一内核）

> 生成：2026-09-08
> 定位：DSH 内核做底层架构的 AI 全自动工作台，普通用户双击 .exe、扫码登录、一句话下达任务、AI 自动把事办完。
> 依据：DSH 架构铁律（业务能力=DSH 插件/服务；AI 主动决策动作=类型化工具；普通 CRUD=服务直调；长外部任务=任务队列）+ 需求清单 20 条 REQ + 对标产品。

---

## 0. 架构基座（决定每个功能怎么落地）

| 能力类型 | DSH 落点 | 举例 |
| --- | --- | --- |
| AI 主动决策执行的动作 | 类型化工具（内核已 9 个） | 保存草稿、查账号、查待接待 |
| 普通增删改查 | 服务直调（不进 agent 循环） | 删草稿、改账号分组 |
| 长外部任务 | 任务队列（JobQueue 状态机/重试/恢复/共享浏览器） | 登录/发布/同步/客服 |
| 数据所有权 | 产品数据店（schema 版本化原子存储） | 账号/素材/草稿/发布/数据/接待唯一事实源 |
| 前端 | 自研显示层（不存第二份会话状态） | React + Vite |

## 5. 开发顺序（P0 → P2）

P0（核心价值链路，发布前必须）：
1. 3.4 发布回传真实平台 ID/链接（抖音可用，可实测打通）
2. 2.6 每步截图留痕
3. 2.7 全功能对话自动化
4. 1.3 多账号矩阵 + 1.4 账号健康监测（小红书被封正需）

P1（对标补齐）：
5. 1.6 代理真生效；6. 2.5 任务队列接登录/发布/同步；7. 2.9 技能/定时自动化；8. 3.1 视频生成稳定性；9. 3.8 视频号/快手

P2（体验/完整性）：
10. 账号画像趋势、通知中心、多模态、定时发布验
