# 能力台账 v1.0（唯一的开发待办）

> 日期：2026-10-11 ｜ 依据：ADR-005、标准 1「没有工具的能力不算能力」
> 口径：一条能力 = 一句用户会说的话 → 归属管家 → 调用的工具 → 页面上看得见的结果
> 数据来源：口径与数字**一律以门禁当场计数为准**（`qa/verify-marvis-progress.mjs` / `qa/verify-kernel-tools.mjs`）；
> 本表 §0 已按 2026-10-13 门禁实测刷新（旧文写的「49 条 + 18 个」是 2026-10-11 的快照）。
