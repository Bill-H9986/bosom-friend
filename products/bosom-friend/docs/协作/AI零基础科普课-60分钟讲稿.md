# AI 零基础科普课（60~90 分钟讲稿）

> 听众：**完全不懂 AI 的普通人**（运营、客服、老板、家里人）　｜　讲师：产品负责人
> 例子全部取自 Bosom Friend 项目的**真实口径与真实缺陷**，不编、不夸大；每个关键说法都在文末「出处」里能查到。
> 用法：每个【模块】= 一组 PPT；表格的**一行 = 一页**；标着「讲师台词」的段落可以直接照念。

## 0. 开场：先卸掉恐惧（3 句话，约 3 分钟）

1. 今天不教你怎么"学 AI"，只讲三件事：**它是什么、它能干什么、它什么时候不能信**。
2. 你不需要懂技术名词。今天出现的每一个名词，我都会先用生活里的事讲一遍，再告诉你它在**我们这套系统里对应哪个按钮、哪个功能**。
3. 全场只有一条原则，请先记住：**要么是真的，要么明确说没有。** 这是产品的口径，也是你跟 AI 打交道的护身符。

## 模块一　用生活比喻讲清 AI（11 个概念）

> **模块核心一句话（先写在白板上）**：AI 不是一个"知道一切的人"，它是一个"**很会接着你的话往下写的机器**"。

⚠️ **下表第 2 列全部是比喻，不是事实。** 第 1 列是各行业通用的大白话说法，第 3 列是本项目里真实存在、能指得出来的东西。

| 概念（大白话） | 生活比喻 | 在本系统里对应什么（真实，可指） |
| --- | --- | --- |
| **大模型 / LLM（会接着你的话往下写的机器）**：它不是从数据库里"查答案"，而是根据你给它的全部文字，一个词一个词地猜"下面最像的那个词"，一路猜出一整段。 | 打个比方：一个博览群书、但**从没进过你公司门**的实习生。你问什么他都接得上，语气还特别稳，可他不知道你家的真实情况。 | 设置 →「自定义大模型」里你配的那个模型；对话、写稿、客服回复都靠它。系统**不内置任何大模型**，也没有默认型号。 |
| **提示词 prompt（你交给它的那张"交办单"）**：你输入的那段要求就是提示词；写得清不清楚，直接决定产出稳不稳定。 | 打个比方：给新同事的交办单——做什么、给谁看、多长、什么口吻、交什么格式。同一个人，交办单潦草，交回来的活就潦草。 | AI 助手侧栏里你打的那句需求就是提示词；口播稿、标题、文案、接待话术都靠它约束。学习计划 P0 的第一项产出，就是把这些散落的写法收成一份《提示词规范》。 |
| **Token（按"米"称重计费的碎块）**：模型不按"字"算账，按 token 算；输入和输出都要计。 | 打个比方：**按米下锅**。你说的话和它说的话都要上秤，秤的单位不是字，是 token。（通用常识：同一句话，中文通常比英文更费 token。） | 条目 14 的真实实测：文本接口**确实给用量**（非流式响应顶层就有 `usage`，含 prompt_tokens / completion_tokens / total_tokens；流式要带 `stream_options.include_usage=true` 才在倒数第二帧给出）；**图片和视频接口没有任何用量字段**，只能按张数、秒数算。 |
| **上下文（它这一次能"看见"的全部内容）**：它没有记忆，每次只看得见这次递给它的那一叠东西。 | 打个比方：**一张有限的桌面**。桌上摆着这次要用的全部材料：规则、工具说明、前几轮对话、刚查到的笔记、你这句话。桌面摆满了，最早摆上去的就被挤下桌。 | 四类语境（领域 / 约束 / 历史 / 本机真实失败）写进语境文件，会话建立时自动注入；提示词里只剩"这次要干什么 + 这一轮检索到的东西"；知识笔记按需注入。助手还知道**你正在看哪个页面、哪条记录**——换对象，回答跟着换，这也是上下文。 |
| **幻觉（一本正经地胡说）**：它会用很通顺、很自信的句子，说出根本没发生过的事、不存在的数据。 | 打个比方：实习生把"我猜大概是这样"报成了"**我确认过了**"，语气还特别笃定。 | 要求二 **R3「无源不显示」**：页面上任何数字必须能追溯到一条采集记录（来源 + 时间），追溯不到就显示「**未采集**」，**禁止用 0 占位**；**R4「失败即呈现」**：平台没给、网络断了、权限不够，如实显示原因，**禁止用模板 / 示例 / 旧缓存冒充结果**。知识库那条链路的门禁判据是"模型**真的引用到**专属事实"，不是"回答得挺像"。 |
| **模型配置 BYOK（自带钥匙）**：BYOK = Bring Your Own Key，用你自己的钥匙调模型；系统不内置模型、不替你付钱。 | 打个比方：**自带食材进共享厨房**。锅（软件）不要钱，食材（模型额度）你自己买；没带食材，厨房不会给你变出一盘菜，只会递来一张"先去买菜"的纸条。 | 设置 →「自定义大模型」：填接口地址 / API Key / 模型名，可存多个服务、多个模型并切换当前模型；图片模型、视频模型按用途登记；保存后立刻探活。**只内置服务商地址，不预置任何模型目录与默认型号。** 没配置时的固定回复是"未接入任何大模型，请先在 设置 → 配置大模型 中填写你的 API 地址和密钥"，不许假装生成。密钥只住凭据通道（.credentials.yaml），**禁止硬编码、禁止写进业务数据文件**。 |
| **多模态：文生图 / 图生视频（换一双"手"来干活）**：模型不只会写字，还能按文字出图、按一张图生成几秒视频；不同形式是不同的模型。 | 打个比方：文字是"**口述下单**"，图片是"**先递一张样板照**"，视频是"**让样板照自己动起来几秒钟**"。同一张嘴，换的是不同的手。 | 图片、视频是不同的模型，在设置里按用途分开登记；生成有分辨率 / 画幅的约定，图生视频有"首帧"的约定；做一条 AI 带货片要走九步工序（脚本 → 配音当母时钟 → 分镜表 → 参考图集 → 逐镜生成 → 时间轴校验 → 组装 → QC）。 |
| **数字人（给它一张固定的脸、一个固定的嗓子）**：让 AI 替你出镜口播。 | 打个比方：给实习生做工牌头像和一段配音，让他上台替你念稿。关键不是"像人"，是**每一镜都得是同一个人**。 | 「我的数字人」里一个形象 = 一张形象图 + 一个固定音色 + 一种念法；长视频里只有"**数字人口播**"这一类出镜形式才要选形象。真实踩过的坑：**DEF-088「跳人」**——明明用一个数字人，画面里的人每隔几镜就换一个；**DEF-175**——"场景种草"里走过的那个人，根本不是形象库里的那位。 |
| **RAG / 知识库检索（先查资料，再回答）**：回答之前先去你的资料里搜一遍，把搜到的片段递给模型当"已知知识"，再让它写答案。 | 打个比方：**开卷考试**。先翻到那一页，再动笔；翻不到就老实说翻不到，别硬编。 | 知识库 **390 篇**笔记，按"结构 / 契约 / 来源"三要素检索，命中片段按需进模型上下文（**目前没有用向量库**）；哪一次注入了哪几篇要留痕，「注入预览」能让你先看一句话会命中哪些笔记（连被排除的审计笔记也列出来）；接待规则没接住客人提问时，模型也**带着你的知识库和成功样例**回答，账本里记着命中了哪几篇。 |
| **Agent 智能体与工具调用（会说话，还会动手）**：它自己决定"调哪个工具、按什么顺序做"，一步步把事办完，并在页面上留痕迹。 | 打个比方：从"只会写方案的实习生"升级成"**能跑腿的助理**"：能开门、能复印、能提交。但跑腿的本事是公司发的门禁卡，**不是他自己长出来的手**。 | 内核里有一批业务工具（bosom_ 开头的那些），工具面被刻意收敛过（**35 个 → 14 个**），"纯文本会话"里模型**连工具都看不到（0 个）**。会动手还要有闸门：任务卡按意图拦 / 放；动作卡（"去发布"）点了才在前端执行并回传截图；「我的任务」里每一步的调用与结果都看得到，能中断、能继续。 |
| **微调（把"通用生"教成"你家的人"）**：拿一批"输入 → 正确产出"的真实样例再训一下，让它更像你们家的风格与判断。 | 打个比方：**入职培训**。不是教他识字（那是别人早就教过的），是教他"我们家的写法、我们家的规矩"。 | 知识库的蒸馏账本正在攒这种样本（每次生成 / 对话留一条结构化样本：指令、输出、模型、注入了哪几篇、状态、评分），能一键导出成微调数据集；评分够高的经验还能"升格为技能"。学习计划的 P2，就是用这些真实数据训一个小模型。 |

### 1.1 比喻的边界（讲师必须补的 6 句话，约 3 分钟）

1. **"实习生"不是人**：它没有理解、没有意图、也没有责任心。它说错话不是"撒谎"，是它生成了"最像答案的那段话"。
2. **"桌面被挤下桌"不是真的删记忆**：它本来就没有跨会话记忆，只是这一次的输入里不再包含那段内容（术语叫"截断"）。
3. **"称米"的米不是字数**：token 有自己的一套切法，同一个意思换个说法，米量就不一样。
4. **"开卷考试"翻的是"被检索命中的片段"**：翻不翻得到，取决于检索命中，跟"模型聪不聪明"是两件事。
5. **"自带食材"意味着账单在你身上**：软件不收费，模型调用按你自己的账号计费；没带食材时它不是"罢工"，是**固定回一句"请先配置大模型"**。
6. **"能动手"来自工具和闸门**，不是模型本身能操作你的电脑：给它的工具是被挑过的业务工具，编码类的工具（命令行、文件读写、子代理等）**没有给它**。

## 模块二　与 AI 打交道的 5 条铁律

> 讲师开场语：下面这 5 条，每一条都是我们自己**踩过坑之后**写进规矩里的。你不需要记住原理，记住这 5 句就够。

| # | ❌ 普通人最容易犯的错 | ✅ 正确做法 | 📌 依据（本项目真实证据） |
| --- | --- | --- | --- |
| 1 | 把"说得像"当成"是真的"：AI 给一串数字、一条链接、一个结论，看着像就复制进周报、发给客户。 | 任何数字和结论都先问一句"**出处是什么**"。有来源 + 有时间才算数；没有就写「未采集」，**不要自己补 0，也不要让它猜一个**。 | R3 无源不显示、R4 失败即呈现；作品行 AI 复盘里"没采到的指标如实说『平台未采集』，**不被当成 0 送进模型**"。 |
| 2 | 把 AI 当许愿池：甩一句"帮我写个爆款文案"就等成品，不满意就骂模型笨。 | 按"**交办单四件套**"写清楚：角色（你是谁）、任务（做什么）、约束（多长、什么口吻、什么不能出现）、输出格式（标题/正文/标签分开），最好再给一两个例子。 | 学习计划 P0 的四段式（角色、约束、示例、输出格式）；**DEF-044** 就是"指令没被正确理解"的活例——"写笔记"被执行成了"发布"。 |
| 3 | 让 AI 替你拍板：顺手发出去、顺手删掉、顺手多生成几条。 | 不可逆的动作（**删数据、改名字、真实发布、真实同步**）先说清"做什么、哪个账号、影响范围"，**等人同意**；生成图片 / 视频 / 配音 / 数字人是**真实花费**，用户没明确要求就不要主动触发。 | 铁律 #9.6「不可逆操作必须先问」；真实发布 = **不可撤回的对外动作**，必须先获批；没得到用户明确的发布指令就发出去，**等同于伪造用户的决定，按红线处理**。 |
| 4 | 出问题只会"再试一次 / 换个更大的模型"，从不问错在哪一层。 | 先分清是**模型错 / 工具错 / 环境错**；同一场景**连续失败 2 次就停下来**，把现象和已试过的动作一起报出来；新问题先登记再修。 | 智能体纪律"同一场景连续失败 2 次即停止"；**DEF-050** 的真凶不是模型不行，而是**超时预算没有按实测标定**（轮询预算 < 真实耗时 ⇒ 静默降级）；学习执行卡的警戒线：遇到报错就丢给 AI，等于把最好的老师推开。 |
| 5 | 把"估算"写成"实测"，把 0 当成"没有"。 | 口径分三档并**分别标注**：**A 实测**（文本 token，真的从响应里拿到了）、**B 估算**（图片/视频按张数秒数；拿不到用量时按字符换算）、**C 墙上时间**（本地计时）。写 0 之前要能说清是"真的没有"还是"没取到"。 | 条目 14 的实测与红线——"**硬编码的 0 比『没有字段』更糟：它看起来像实测值**"；不许把 B 写成 A；同族问题 **DEF-050**（弱信号冒充强信号）。 |

**讲师台词（逐条照念）**

- 第 1 条："我们今天最硬的一条规矩就是这句话——**要么是真的，要么明确说没有**。做到它靠的不是让 AI 更聪明，而是**在结构上让它没法造假**。"
- 第 2 条："提示词写得清楚，不是给 AI 添麻烦，是省你自己的时间。**你在提示词上省的每一分钟，都会在返工上还回来。**"
- 第 3 条："AI 能力越大，越要给它装刹车。**装刹车不是不信任它，是让它敢往前跑。**"
- 第 4 条："『换个更大的模型』是最常见的一种偷懒。项目里已经证明：**真正的坑，常常跟模型一点关系都没有。**"
- 第 5 条："数据里最危险的从来不是『没有数字』，而是**一个看起来很像真的假数字**。"

## 模块三　AI 的能力边界

> 讲师开场语：会用它的人，不是知道它能干什么的人，是**知道它什么时候不靠谱**的人。

### 3.1 AI 做不到什么（以及本系统怎么如实呈现）

| AI 做不到什么 | 真实表现与本系统的做法 |
| --- | --- |
| **不知道你家的真实情况**（不查资料就答） | 生成 / 对话前先按指令**检索知识库**（390 篇），命中才当"已知知识"进上下文；没命中就明说不知道。 |
| **不能保证数字和事实准确** | R3：任何数字要有**来源 + 时间**，追溯不到显示「未采集」，禁止 0 占位；R4：失败如实显示原因。 |
| **没有跨会话记忆** | 每次只带这次给它的上下文；产品规则、硬数字、踩过的坑写进**语境文件**，会话建立时注入。 |
| **不能替你登录平台** | 登录走**平台官方扫码**，这是真人动作；登录失效时明确提示"请重新扫码"，并给一键重登入口，而不是偷偷重试。 |
| **不能保证平台一定接受发布** | 发布成功 = 页面出现发布记录 + **平台真实作品 ID / 可打开链接**，缺一项都不算成功；被平台拒绝就展示**平台原文原因**。 |
| **不能让画面里的人一直是你选的那张脸** | **DEF-088「跳人」**：同一支片里每隔几镜换一个人；**DEF-175**："场景种草"里走过的人不是选定形象。所以"人不一致"是真实发生过的问题，不是危言耸听。 |
| **不能保证视频画面里的文字是对的** | 在分镜提示词里主动要求模型"画文字"是**实测会翻车**的写法（会生成臆造品牌），命中就要提示人工确认。 |
| **不会自己"花钱、下单"** | 图片 / 视频 / 配音 / 数字人都会产生**真实费用与额度消耗**，用户没明确要求时不主动触发。 |
| **不能替你做敏感内容判断** | 涉及**价格、合同、法律、医疗**等敏感话题，只提供**模板级回复**并提示用户人工确认。 |
| **不能消除平台风控风险** | 主动给非粉丝发私信、批量点赞/关注/评论、刷量互赞互粉是**红线，UI 上不提供入口**。 |
| **不能把"看起来做完了"当成做完** | 铁律 #13：**没有端到端证据不算完成**；门禁里 **SKIP ≠ PASS**，环境不满足要如实跳过并写原因。 |

### 3.2 什么情况必须人工确认（本项目的真实口径）

| 场景 | 谁确认 | 本项目真实口径 |
| --- | --- | --- |
| 删数据、改名字、真实发布、真实同步 | 用户 | **不可逆操作必须先问**：先说明"做什么、哪个账号、影响范围"，等用户同意（铁律 #9.6）。 |
| 真实发布 | 用户 | 只有用户**明确说"发布到某平台"**，才出现「去发布」动作卡；**没得到明确发布指令就发出去 = 伪造用户的决定，按红线处理**。 |
| 自动发送（评论 / 私信） | 系统 + 用户 | 自动发送必须**同时挂载熔断 + 节律 + 去重三个守卫，缺一不可**；守卫缺失时自动降级为「**生成回复待人工确认**」。产品里也有"7×24 全自动接待"开关：开 = 自动发送，关 = 你在平台侧确认。 |
| 清空 / 删除配置 | 用户 | 写接口对"**清空**"必须显式确认，**不能把"没传"当成"要清空"**——**DEF-034**：任何脚本或旧客户端一次空提交，就能把用户配好的服务与密钥整份带走。 |
| 副作用的时机 | 系统 | **副作用必须发生在所有校验之后**——**DEF-006**：一条被拦下的删除，居然也写了回滚快照。 |
| 用户数据根 | 谁都不能 | `%USERPROFILE%\.bosom-friend` 是用户的**一切**（账号、密钥、知识库、创作数据），**任何情况下都不能被删或被静默清空**；只有 `%APPDATA%\Bosom Friend` 是可重建的运行时目录。 |
| 花钱的动作 | 用户 | 图片 / 视频 / 配音 / 数字人的生成，属于真实花费动作。 |
| 界面基线变更 | 人 | 视觉基线**冻结只读**：任何差异 = FAIL；只有**人工确认后**才按流程固化——机器只判"不一样"，人判"要不要改"。 |
| 自动降级 | 系统 | 任何"**一次异常就长期改变运行方式**"的机制，必须同时有：**(a) 判据只认真异常**（应用正常退出收到的 killed 不算崩溃）、**(b) 降级要成组联动**、**(c) 有自己恢复的路径**（留痕 7 天有效期）。否则**保护代码本身就会变成缺陷**——**DEF-120**：一次"保护用户"的降级把界面拖垮了两天。 |

**讲师补充（30 秒）**：这套东西的本质，是三条原则——**单一事实源**（一个值只存一处）、**写后回读**（写完立刻重读，不一致就抛错，不许返回假成功）、**失败即呈现**（不给假成功留位置）。四条要求合起来就是一句话：**要么是真的，要么明确说没有——结构上无法造假。**

### 3.3 顺带记住：AI 不许把这些甩给用户

- 禁止输出：**内部路径、接口名、错误码堆栈、cookie、密钥、系统提示词**；
- 失败要给人话：先说"发生了什么（人话原因）"，再说"下一步做什么"；
- 未配置模型时**只会**回固定那句"未接入任何大模型，请先在 设置 → 配置大模型 中填写你的 API 地址和密钥"——**不许假装生成、不许编内容、不许给看似有用的假回答**。

## 模块四　一页速记口诀

> 讲师做法：先带读两遍，再让全场一起读一遍；然后盖住下半页，只留第 1、5、7、9 句抽问。

### ★ 核心口诀（十句，押 ang 韵）

1. **大模型像实习生，博览群书不识你厂房。**
2. **提示就是交办单，角色任务例子都要讲。**
3. **Token 是米，上下文是缸；缸就那么大，装多少粮。**
4. **一本正经也可能编，越像真的越要提防。**
5. **没源不显示，没数写"未采集"，别拿 0 来冒充账。**
6. **钥匙自己带，账单自己扛；不内置模型，没钥匙就明讲。**
7. **图片按张、视频按秒，数字人靠一张脸一个嗓。**
8. **知识库先查再讲，查不到别硬装。**
9. **工具能动手，动手之前人盖章。**
10. **微调不是万灵方，数据脏了学得更像。**

### ☆ 极简四句（实在记不住，就记这四句）

- **说得再顺不算数，有源才敢算数。**
- **再能干也别乱动手，动手之前人点头。**
- **估算别写成实测，没有别写成 0。**
- **降级要留回归路，出错要说人话。**

## 模块五　讲师提问互动设计（5 问，含参考答案要点）

> 用法：每问先给 30~60 秒思考，**先让听众答**，讲师再补要点。第 1、4 题是必问题。

### 第 1 问（检验：幻觉 + 无源不显示）

**问**：AI 说"你昨天那条视频播放量 1.2 万"，你敢直接抄进周报吗？为什么？

**参考答案要点**
- 模型生成的是"最像答案的那段话"，不是从数据库查出来的结果；**话说得流畅 ≠ 说得对**。
- 产品口径 **R3 无源不显示**：页面上任何数字必须能追溯到一条采集记录（**来源 + 时间**）；追溯不到就显示「**未采集**」，**禁止用 0 占位**——"没有数据"和"数据是 0"是两件事。
- **R4 失败即呈现**：平台没给、网络断了、权限不够，如实显示原因，禁止用模板 / 示例 / 旧缓存冒充结果。
- 作品行 AI 复盘就是这样做的："没采到的指标如实说『平台未采集』，**不被当成 0 送进模型**"。
- 讲师追问："那怎么才算确认是真的？"→ **平台真实作品 ID / 链接、页面可见结果、可复现步骤**（铁律 #13：没有端到端证据不算完成）。

### 第 2 问（检验：上下文 + 提示词）

**问**：同一句话，你上午问和下午问，答案不一样；交给同事去问，结果又不一样。这说明什么？

**参考答案要点**
- 模型每次都是**重新"接龙"一次**，不是从同一个抽屉里取同一份答案。
- **上下文 = 它这一次能看见的全部内容**（你这句话 + 历史 + 检索到的笔记 + 规则），换个时刻、换个人，看到的东西就不一样。
- 想让结果稳定：① 把要求写清楚（角色的四件套：角色/任务/约束/输出格式 + 例子）；② 把资料放进去（知识库检索命中后注入）；③ 把结论落成**可复现的证据**。
- **"同一句话再问一遍"不是验证方法**——它只是又生成了一次。
- 讲师提醒：不要答成"模型有情绪、记仇、敷衍你"。

### 第 3 问（检验：BYOK + 诚实的失败态）

**问**：客户说"我这台电脑上 AI 不回话，只弹一句话，是不是软件坏了？"

**参考答案要点**
- 大概率不是坏了。**系统不内置任何大模型**，模型要用户**自带钥匙（BYOK，自带密钥）**：在设置里填**接口地址 / API Key / 模型名**，保存后立刻探活。
- 没配置时的固定回复是："未接入任何大模型，请先在 **设置 → 配置大模型** 中填写你的 API 地址和密钥。"
- 铁律 #7：**不许假装生成、不许编造内容、不许给看似有用的假回答**；配置了就必须真调用，失败要如实说原因（**超时 / 限流 / 无效 Key**）。
- 讲师追问："那把公司的钥匙硬编码写进程序里行不行？"→ **不行**：密钥只住凭据通道（.credentials.yaml），**禁止硬编码、禁止写进业务数据文件**。

### 第 4 问（检验：Agent + 人工确认）——**全场必问**

**问**：你已经让 AI 把一条内容写好了，接下来它能自己发出去吗？

**参考答案要点**
- 默认**不能**。只有用户**明确说"发布到某平台"**，才出现「去发布」动作卡；**没得到明确的发布指令就发出去，等同于伪造用户的决定，按红线处理**。
- **发布成功 = 页面出现发布记录 + 平台真实作品 ID / 可打开链接**，缺一项都不算成功；被平台拒绝要展示**平台原文原因**。
- 真实发布是**不可撤回的对外动作**，必须先获批（铁律 #9.6）。
- 自动接待发送还要有**熔断 + 节律 + 去重三个守卫，缺一不可**；缺守卫时自动降级为「生成回复待人工确认」。
- 讲师追问："不是号称全自动吗？"→ 全自动指的是"**用户说一句话，AI 把事办完**"，不是"AI 不需要你的指令"。**这两件事不冲突。**

### 第 5 问（检验：成本记账 + 诚实）

**问**：成本报表里有一格是 0，你写上"这条业务没有消耗"——这句话可能错在哪？

**参考答案要点**
- 0 可能是"**真的没消耗**"，也可能是"**没取到数**"；这两件事必须分开写。
- 条目 14 的实测结论：文本接口**确实给用量**（流式要带 `include_usage`），是我们**中间层把它丢了**；图片 / 视频接口**确实没有用量**，只能按张数 / 秒数估。
- **红线**：三档（**A 实测 / B 估算 / C 墙上时间**）必须**分别标注**；不许把估算写成实测、不许把 0 当实测——"**硬编码的 0 比『没有字段』更糟，因为它看起来像实测值**"。
- 同类问题 **DEF-050**：弱信号冒充强信号。

## 收尾：讲师照念的 3 句话（约 2 分钟）

1. **它很能干，但它不知道你家的事**——所以资料要给它（知识库），要求要写清（提示词）。
2. **它永远说得很有道理，所以永远要问出处**——有来源 + 有时间才算数；没有就说"没有"。
3. **它能动手，但钥匙在你手里**——发布、删除、花钱，都要人点头。**要么是真的，要么明确说没有。**
