## 五、纪律（本轮踩过的坑，逐条钉死）

1. **先测试，再打包**：出包入口已接 `verify-before-package.mjs`，红了拒绝打包（机制，不靠自觉）。
2. **改前端只刷新，不重启**：换 dist 是静态文件，刷新即可；`dev-web.ps1` 的固定开销是 1.5–3 分钟，别浪费。
3. **改后端才重建**：server/kernel 改完必须 `dev-web.ps1`（含 lib 同步与注入副本刷新）。
4. **一文件一路**：并发时同一文件同时刻只有一路在改（写范围表）。
5. **每批改动跑 `tsc`/构建 + 定向门禁**，不留到最后统一验。
6. **实时记录**：每节点写工作日志 + 缺陷台账 + 活记忆，跑 `memory-sync`。
7. **不擅自打开会改变行为的开关**：角色面（D1）这类，先拍板再动手。
8. **打包脚本只许 ASCII + 语法自检**：本次已因中文注释踩过 PS 5.1 解析坑。
