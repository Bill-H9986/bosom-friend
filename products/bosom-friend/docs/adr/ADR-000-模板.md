# ADR-000：决策标题（一句话）

> 状态：提议 / 已接受 / 已废弃 / 被替代
> 日期：YYYY-MM-DD
> 关联：REQ-xxx / DEF-xxx（可多个；无则写“无”）
> 评审：参与人姓名 + 结论 + 日期

## 背景

- 要解决什么问题、当前做法哪里不行。
- 为什么现在必须做决定。

## 决策

- 明确写“我们决定怎么做”，不含糊。
- 涉及 DSH 边界的，写清楚：内核 / 前端 / 数据各自归谁。

## 后果

- 正面：带来什么。
- 负面/代价：牺牲了什么、引入什么约束（必须写；没有代价的决策不存在）。

## 备选方案（至少一个）

- 方案 B：……；不选原因：……

## 验证方式

- 怎么证明这个决策落地且有效（门禁项、测试、页面可见结果）。

## 链接

- 相关代码、测试、文档路径。
