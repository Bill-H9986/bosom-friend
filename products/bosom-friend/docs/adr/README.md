# 架构决策记录（ADR）索引

本目录存放 Bosom Friend 的重大技术决策，编号唯一、终身不变。目的：把“为什么这么设计”写下来，防止反复争论、反复返工。

## 规则（来自《工程化流程与可追溯体系规范》）

1. 编号从 ADR-000 起，文件名 `ADR-NNN-主题.md`，没有编号就没有立项。
2. 状态只有四种：提议 / 已接受 / 已废弃 / 被替代。
3. 必填字段：日期、背景、决策、后果、参与评审、关联需求或缺陷、链接。
4. 任何影响 DSH 边界、进程结构、数据格式、对外接口的改动，必须先写 ADR 并评审通过，再动代码。
5. 被替代的 ADR 不删除，只在状态栏注明“被 ADR-NNN 替代”。
