## 八环逐条（照念即可）

### ① 选题
**念**：`帮我想 3 个「35 岁零基础转行无人机」的图文选题。`
**它做了什么**：调 `bosom_steward_dispatch` 转交创作管家 → 创作管家给出 **3 个选题**（含每个选题的切入点）
**看哪里**：「我的任务」里那条转交后的对话

### ② 写稿并落草稿
**念**：`用第 1 个选题写一条小红书图文，标题和正文都给我，然后存进草稿箱。`
**它做了什么**：7 步工具（读草稿 → 生成脚本 ×2 → 落草稿）→ **草稿 73 → 74**
**看哪里**：草稿箱顶部新出一条，标题「35岁裸辞转行，我靠这招拿到无人机执照直接上岗」

### ③ 出图（封面）
**念**：`给草稿 cnt-zta5i2xx 生成一张封面图。`
**它做了什么**：`bosom_content_make_cover` → 封面挂到那条草稿
**看哪里**：草稿卡片上有封面图（主标题「35岁裸辞转行」）

### ④ 查草稿
**念**：`草稿箱里最新那条是什么？把标题和有没有封面告诉我。`
**它做了什么**：列出草稿 → 取详情 → **如实回答"标题 + 有封面"**
**看哪里**：与草稿箱实际内容对照

### ⑤ 发布（**已闭环，最硬的一条**）
**念**：`把草稿 cnt-39l1qv32 发到抖音，标题压到 20 字以内，正文和话题保持原样，发完把平台返回的作品链接给我。`
**它做了什么**：9 步工具（含 `bosom_content_update_draft` 压标题、`bosom_publish_draft` 提交）
**结果**：发布记录 `rec-1z0frnvr` **status=1**、**平台作品 ID `7695987004038843702`**
**看哪里**：抖音「小雅日记」里能看到这条；发布记录里能看到作品 ID
**（改前两次都是 status=-1 失败 —— 引擎那两处修复是这一条能成的直接原因）**

### ⑥ 数据回流
**念**：`同步一下抖音和小红书两个账号的作品数据。`
**它做了什么**：`bosom_platform_sync_now` → 同步完成
**它怎么说的（专业口径）**：本次匹配到 **1/3** 条作品拿到真实播放量，**其余 2 条未采到数据是平台还没回传，不是 0 次播放**
**看哪里**：数据中心的播放量

### ⑦ 复盘
**念**：`我最近发出去的作品里哪条表现最好？为什么？`
**它做了什么**：`bosom_data_works` → 给出最好那条（**播放 397 / 评论 30**）**＋ 3 条理由 ＋ 与其它条的横向对比**
**看哪里**：与数据中心的数据对照

### ⑧ 接待
**念**：`有新的评论或私信需要我回吗？`
**它做了什么**：`bosom_reception_list_pending` → 找到 **1 条待处理**（抖音私信「丸子叨叨叨」），并说明这条属平台提示型消息
**看哪里**：接待页
