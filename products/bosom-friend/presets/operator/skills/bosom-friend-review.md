# 技能 · 复盘口径｜归属管家：运营管家

> 复盘只讲**有数据支撑**的结论；样本不够就先说样本不够。

## 适用场景
- 用户问「哪条数据好」「为什么这条播放高」「下一步发什么」。
- 不适用：只报数字（那是 `bosom-friend-ops` 的读数步骤）；平台热点与选题（创作侧）。

## 步骤
1. **先取数**：`bosom_data_works` 拿已发布作品、每条作品的播放/点赞/评论与链接，以及 `availability`（哪些指标有信号）与数据更新时间；必要时 `bosom_platform_sync_works`（`limit`）回看本地发布记录。
2. **先判样本**：关键指标「无信号」、或可比作品只有 1~2 条时，**直接说样本不足**（例如「平台还没采到足够的播放数据，先攒一周再看」），不要硬分析。
3. **只在同平台内比**：拿同一平台的作品互相对比（不同平台的量级不可比），把每条的优势项写清楚（播放高 / 点赞高 / 评论高）。
4. **结论必须能指到数字**：每条结论都要能指回第 1 步返回里的某个字段；指不到的就不说。
5. **给可执行建议**：说清改哪一项（标题、形式、时长、发布时段），而不是「多发优质内容」这类正确的废话。
6. **分清事实与推测**：能证明的写「数据显示…」；只是猜测的写「可能是…，需要再发一条同类内容验证」，不要写成因果结论。

## 判据
- 结论里的每个数字都能在 `bosom_data_works` 的输出里找到。
- 无信号指标不参与排序、不参与结论。
- 样本门槛：可比作品少于 3 条、或关键指标无信号时，只给「样本不足 + 怎么攒样本」。
- 建议可执行 = 指明「改哪一项、改成什么」。

## 反例
- 把「无信号」当成「表现差」，或把 0 当真实播放量参与排名。
- 用一条作品的数据得出「封面决定播放量」这类因果结论——没有对照证据。
- 给「要多发内容」「要提升质量」这种无法执行的建议。
- 把不同平台的作品混在一张榜里比。
- 为了显得专业，编造同行数据或平台算法规则。
