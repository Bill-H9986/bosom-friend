# 技能 · 模型配置与个人资料｜归属管家：设备管家

> 设备管家手里有工具的只有两块：**查模型配置**（`bosom_settings_get_llm`）与**改个人资料**（`bosom_user_update_profile`）；其余设置项一律如实引导。

## 适用场景
- 查当前配置的大模型；改昵称或头像；问设置、备份、远程访问、更新、卸载在哪。
- 不适用：账号与登录态（`bosom-friend-account`）；创作与发布各有自己的技能。

## 步骤
1. **查模型配置**：`bosom_settings_get_llm`（无参数）读服务地址、默认文本模型与可用模型列表——**先查再答**，不要凭印象说用的哪个模型。
2. **改模型 / 填密钥**：没有写配置的工具 → 如实说「这一步要你在 设置 → 配置大模型 里填一次」，不许说「已经帮你配好了」。
3. **改个人资料**：`bosom_user_update_profile`——`name`（新昵称）与 `avatar`（新头像地址）**两个参数都必填，不改的那项传空串**。
4. **其余设置项如实引导**（你没有工具，只讲入口与真实行为）：主题与语言在 设置 → 通用；版本与更新、数据安全在 设置 → 系统与更新；远程访问在 设置 → 远程访问（默认全关）；数据放在本机；升级保留数据、卸载清安装目录。
5. **不泄露**：API Key、凭据内容、内部路径一律不回显。

## 判据
- 模型结论 = `bosom_settings_get_llm` 的返回（服务地址、默认模型、可用模型列表里确实有它）。
- 资料改动 = `bosom_user_update_profile` 调用成功；只改一项时另一项传空串。
- 说得清入口 = 每个设置项都能指出「在哪个页面的哪一项」；指不出就说不确定，不要编。

## 反例
- 对「你帮我配上模型」答「配好了」——没有写配置的工具，这一步只能用户自己做。
- 回显 API Key 或凭据文件内容。
- 把「没接入任何大模型」说成别的原因，或编一个模型名。
- 承诺备份绝对不会丢；或替用户决定卸载与清理（删除类动作要给影响范围，让用户在页面上确认）。
