## 七、没做的（如实挂账）

1. **G3 数据不会越用越乱**：单写入点 + 事务语义 + 迁移器，**未做**；
2. **「谁在干」没有实质分派**：61 条任务的 `agentRole` 全是 `steward`，其他管家 0 条；
3. **preset 组装仍不生效**：要打通须改 DSH 官方包（`packages/sdk/server`）；
4. 知识蒸馏升级 / 远程访问（等你拍板）/ 代码分区；
5. **记忆层 107.3 需要按周看趋势**，不是一晚能验完；
6. 抖音互动指标由平台滞后回传，属口径不是缺陷。

## 八、今晚的四次自我纠错

1. **错判记忆层**：反复说「完全没动」，实际四层全有实现——**判「做没做」要去看载体**；
2. **探针字段写错**：服务端要 `prompt`，我发 `message`，几次「空对话」被我当成「模型没用工具」——**验证工具本身也要被验证**；
3. **改提示词无效**：DEF-274 第一次只改技能与规则，实测模型照旧只报一个口径——**能力要长在工具返回上**；
4. **字符串转义踩三次**：模板字符串里写裸反引号，`tsc` 报错、server 起不来——**改文件先想清它在什么字符串上下文里**。
