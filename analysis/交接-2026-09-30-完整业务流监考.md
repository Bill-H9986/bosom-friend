## 二、环境怎么起（**这是我今晚踩得最惨的坑，别再踩**）

| 坑 | 事实 |
| --- | --- |
| **端口变量** | 是 **`BF_DESKTOP_PORT`**（`bundle/desktop/cordis.patch.yml`：`port: !!js Number(process.env.BF_DESKTOP_PORT ?? 31280)`）。**不是 `BF_QA_PORT`** —— 设错了它就去抢 31280。 |
| **入口** | 必须用 **dev 入口** `products/bosom-friend/launcher/src/bin-desktop.ts`（`node --import tsx/esm`）。<br>`bundle/kernel/runtime/bin-desktop.mjs` **缺前端资源 → 所有路径 404**，别用它。 |
| **数据根** | 用**完整备份**（`Copy-Item ~/.bosom-friend/bosom-friend <临时目录> -Recurse`）—— 账号登录态一起带过去，**不用重新扫码**。<br>空白隔离根会因为「账号未登录 → 需真人扫码」而跑不完。 |
| **起服务** | 必须**后台**起（`run_in_background`）。前台命令跑满时限会被打断，今晚因此中断十几次。 |
| **启动脚本** | `analysis/_start-only.ps1` 写日志到 `analysis/_start-log.txt`；**该文件被占用时启动会失败**，先删再起。 |

### 起隔离实例的完整命令
```powershell
# 1. 复制数据根（副本）
$src = "$env:USERPROFILE\.bosom-friend\bosom-friend"
$dst = Join-Path $env:TEMP ("bf-exam-" + (Get-Date -Format 'HHmmss'))
Copy-Item $src $dst -Recurse -Force

# 2. 后台起隔离实例（端口 31399）
$env:BOSOM_FRIEND_HOME = $dst
$env:DSH_HOME = $dst
$env:BF_DESKTOP_PORT = '31399'
node --import tsx/esm products/bosom-friend/launcher/src/bin-desktop.ts

# 3. 监考脚本指向隔离实例
$env:BF_QA_BASE = 'http://127.0.0.1:31399/bosom-friend/'
```
**冷启动 2-3 分钟**；就绪判据 = `HTTP 200` 且 `31399` 在监听。

### ③ 关键约定：`required: false` 会炸
这个框架的 JSON schema 编译器**只接受省略 `required` 或 `required: true`**；
写 `required: false` 会让**整个插件树加载失败、服务起不来**
（报 `parameters.X.required must be true when present`）。新增工具时注意。
